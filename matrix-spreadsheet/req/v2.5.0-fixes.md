# matrix-spreadsheet v2.5.0 fixes plan

> **For agentic workers:** Execute this plan task-by-task inline (this repository forbids subagents, see `CLAUDE.md`). Steps use checkbox (`- [ ]`) syntax for tracking. A task is done only when its tests pass **and** the test command used is recorded next to the checkbox.

**Goal:** Fix the 22 defects found in the v2.5.0-SNAPSHOT review of `matrix-spreadsheet` — XLSX import crashes and silent truncation, temporal-value round-trip failures, unsafe cell access, append/replace robustness, ODS comment leakage — and align the XLSX and ODS backends where they currently disagree.

**Architecture:** All fixes are local to the existing classes; no new production classes are introduced except two small test helpers (`XlsxTestUtil`, `OdsTestUtil`) that build minimal workbooks in memory so every regression test is self-contained and fast. Ordering: user-facing crashes and data loss first (§1–§3), then consistency and robustness (§4–§7), then docs/perf polish (§8) and verification (§9).

**Tech Stack:** Groovy 5.1.1 (static compilation enforced globally for `src/main`), JUnit Jupiter 6, `groovier-junit`, fastexcel / fastexcel-reader 0.20.2, Aalto StAX.

**Spec:** The review findings are reproduced in the "Findings" appendix at the bottom of this file. The module is already at `2.5.0-SNAPSHOT` (`build.gradle:14`).

- Production code under `src/main` is compiled with `@CompileStatic` globally — do not add the annotation; do add explicit casts where flow typing does not apply (fields, ternaries, closures).

- Use `se.alipsa.matrix.core.util.Logger` for logging; no `println` in `src/main`.
- Tests are Groovy JUnit Jupiter in package `spreadsheet` (or the production package for package-private access); use `groovier-junit` assertions; never coerce GStrings to `String` for assertions.

```groovy
package spreadsheet

import java.nio.charset.StandardCharsets
import java.util.zip.CRC32
import java.util.zip.ZipEntry
import java.util.zip.ZipOutputStream

/**
 * Builds minimal .ods files from a hand-written content.xml for regression tests.
 */
class OdsTestUtil {

  static final String MIMETYPE = 'application/vnd.oasis.opendocument.spreadsheet'
  static final String NS = 'xmlns:office="urn:oasis:names:tc:opendocument:xmlns:office:1.0" ' +
      'xmlns:table="urn:oasis:names:tc:opendocument:xmlns:table:1.0" ' +
      'xmlns:text="urn:oasis:names:tc:opendocument:xmlns:text:1.0" ' +
      'xmlns:dc="http://purl.org/dc/elements/1.1/"'

  /** Wrap the given <table:table> markup in a complete office:document-content. */
  static String contentXml(String tablesXml) {
    """<?xml version="1.0" encoding="UTF-8"?>
<office:document-content $NS office:version="1.2">
  <office:body><office:spreadsheet>$tablesXml</office:spreadsheet></office:body>
</office:document-content>"""
  }

  /** Create a temp .ods containing only mimetype + the given content.xml. */
  static File createOds(String contentXml) {
    File file = File.createTempFile('matrix-test', '.ods')
    file.delete()
    file.deleteOnExit()
    try (ZipOutputStream zos = new ZipOutputStream(new FileOutputStream(file))) {
      byte[] mime = MIMETYPE.getBytes(StandardCharsets.UTF_8)
      CRC32 crc = new CRC32()
      crc.update(mime)
      ZipEntry entry = new ZipEntry('mimetype')
      entry.method = ZipEntry.STORED
      entry.size = mime.length
      entry.compressedSize = mime.length
      entry.crc = crc.value
      zos.putNextEntry(entry)
      zos.write(mime)
      zos.closeEntry()
      zos.putNextEntry(new ZipEntry('content.xml'))
      zos.write(contentXml.getBytes(StandardCharsets.UTF_8))
      zos.closeEntry()
    }
    file
  }

  /** Read one zip entry as UTF-8 text (for asserting on rewritten content.xml / workbook.xml). */
  static String readEntry(File zip, String name) {
    new java.util.zip.ZipFile(zip).withCloseable { z ->
      new String(z.getInputStream(z.getEntry(name)).bytes, StandardCharsets.UTF_8)
    }
  }

}
```

1.3 [ ] Rewrite the row loop in `FExcelImporter.importExcelSheet` (`FExcelImporter.groovy:270-310`) so that (a) header cells that are `null` or have a blank `rawValue` get `"c${index}"` (1-based sheet column index), (b) the header list is padded to `ncol`, (c) missing rows between `startRowNum` and the last emitted row are filled with all-`null` rows, including the trailing gap up to `endRowNum` only when a later row proves the sheet extends that far (do **not** pad past the last physical row — that matches the existing ODS behaviour where trailing repeated empty rows are cut):
```groovy
private static Matrix importExcelSheet(Sheet sheet, int startRowNum, int endRowNum, int startColNum, int endColNum,
                                       boolean firstRowAsColNames, boolean isDate1904) {
  FExcelValueExtractor ext = new FExcelValueExtractor(sheet, isDate1904)
  int startColNumZI = startColNum - 1
  int endColNumZI = endColNum - 1
  int ncol = endColNum - startColNum + 1
  List<String> colNames = []
  List<List> matrix = []
  int nextExpectedRow = startRowNum
  boolean headerConsumed = !firstRowAsColNames
  if (!firstRowAsColNames) {
    colNames.addAll(SpreadsheetUtil.createColumnNames(startColNum, endColNum))
  }
  try (Stream<Row> rows = sheet.openStream()) {
    rows.each { Row row ->
      if (row.rowNum < startRowNum || row.rowNum > endRowNum) {
        return
      }
      // fill gaps left by rows absent from the XML
      while (nextExpectedRow < row.rowNum) {
        if (headerConsumed) {
          matrix.add(nullRow(ncol))
        } else {
          colNames.addAll(SpreadsheetUtil.createColumnNames(startColNum, endColNum))
          headerConsumed = true
        }
        nextExpectedRow++
      }
      nextExpectedRow = row.rowNum + 1
      if (!headerConsumed) {
        for (int c = startColNumZI; c <= endColNumZI; c++) {
          Cell cell = row.getOptionalCell(c).orElse(null)
          String raw = cell?.rawValue
          colNames.add(raw == null || raw.isBlank() ? "c${c + 1}".toString() : raw)
        }
        headerConsumed = true
        return
      }
      List rowList = new ArrayList(ncol)
      for (int c = startColNumZI; c <= endColNumZI; c++) {
        Cell cell = row.getOptionalCell(c).orElse(null)
        rowList.add(cell == null ? null : ext.getObject(cell))
      }
      matrix.add(rowList)
    }
  }
  if (!headerConsumed) {
    colNames.addAll(SpreadsheetUtil.createColumnNames(startColNum, endColNum))
  }
  Matrix m = Matrix.builder()
      .matrixName(sheet.name)
      .columnNames(colNames)
      .rows(matrix)
      .types([Object] * ncol)
      .build()
  m.metaData.isDate1904 = isDate1904
  m
}

private static List nullRow(int ncol) {
  List row = new ArrayList(ncol)
  for (int i = 0; i < ncol; i++) {
    row.add(null)
  }
  row
}
```
Note `"c${c + 1}"` uses the sheet column number so a gap at column B becomes `c2` regardless of `startCol`. If existing tests in `SpreadsheetImporterTest`/`FExcelImporterTest` assert `c1..cN` relative to `startCol`, keep `SpreadsheetUtil.createColumnNames` semantics for the *whole-row* fallback (unchanged) and only use the absolute index for individual gaps — that is what the code above does.

```groovy
/**
 * Copy an xlsx, replacing existing entries named in the map with the supplied text and
 * adding any named entries that do not exist in the source.
 */
static File rewriteEntries(File source, Map<String, String> replacements) {
  File out = File.createTempFile('matrix-test-rewritten', '.xlsx'); out.delete(); out.deleteOnExit()
  Set<String> written = [] as Set
  new java.util.zip.ZipFile(source).withCloseable { zip ->
    new java.util.zip.ZipOutputStream(new FileOutputStream(out)).withCloseable { zos ->
      zip.entries().each { entry ->
        zos.putNextEntry(new java.util.zip.ZipEntry(entry.name))
        if (replacements.containsKey(entry.name)) {
          zos.write(replacements[entry.name].getBytes('UTF-8'))
        } else {
          zip.getInputStream(entry).withCloseable { it.transferTo(zos) }
        }
        zos.closeEntry()
        written.add(entry.name)
      }
      (replacements.keySet() - written).each { String name ->
        zos.putNextEntry(new java.util.zip.ZipEntry(name))
        zos.write(replacements[name].getBytes('UTF-8'))
        zos.closeEntry()
      }
    }
  }
  out
}
```
