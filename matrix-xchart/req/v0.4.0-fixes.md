# matrix-xchart 0.4.0 Review Fixes Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task inline (this repository forbids subagents, see `CLAUDE.md`). Steps use checkbox (`- [ ]`) syntax for tracking. A checkbox is only marked done after the verification commands have been run and recorded.

**Goal:** Fix the bugs and inconsistencies found in the 2026-09-21 review of `matrix-xchart` before the 0.4.0 release.

**Architecture:** All changes are local to `matrix-xchart`. Validation moves to the earliest point with a clear message (`IllegalArgumentException`), builder rules are aligned with what XChart 4.0.4 actually supports (`AxesChart` subclasses, the concrete date/time x-value types XChart can convert), and duplicated helpers are consolidated into `ChartBuilder`/`AbstractChart`. Signatures are only widened, with one deliberate breaking removal: the Groovy-generated `HeatmapChart.setHeatMapMatrix(Matrix)` (Task 2) — a write-only property that every `addSeries` overwrote and nothing read back — is removed and recorded as `breaking:` in the release notes.

**Tech Stack:** Groovy 5.1.1 (static compilation enforced globally via `config/groovy/compileStatic.groovy`), XChart 4.0.4, JUnit Jupiter 6 + `groovier-junit`, CodeNarc, Spotless.

**Spec:** The review findings are recorded in the "Review findings" section at the end of this document (there is no separate spec).

## Global Constraints

- Module is already at `0.4.0-SNAPSHOT` (`matrix-xchart/build.gradle`); do not bump again and do not create git tags.
- Do not add `@CompileStatic` to production classes (global config). Test classes may use `@CompileStatic`.
- Use `IllegalArgumentException` for bad input and `IllegalStateException` for a builder called out of order (matches `ChartBuilder`).
- Use `groovier-junit` `assertEquals`; never coerce GStrings to String for assertions.
- Run chart tests headless: `-Pheadless=true`.
- Verification order for every task: `./gradlew :matrix-xchart:codenarcMain :matrix-xchart:codenarcTest`, then `./gradlew :matrix-xchart:spotlessCheck`, then `./gradlew :matrix-xchart:test -Pheadless=true`. Record the commands in the task when ticking it.
- Do not commit to `main`; create a branch `fix/matrix-xchart-v0-4-0-review` first and ask before pushing.

```groovy
  private static void validateData(List<List<Number>> columns) {
    if (columns == null || columns.isEmpty()) {
      throw new IllegalArgumentException('Correlation heatmap data must contain at least one column')
    }
    List<Number> first = columns[0]
    if (first == null || first.isEmpty()) {
      throw new IllegalArgumentException('Correlation heatmap data column 0 must contain at least one value')
    }
    int nRows = first.size()
    columns.eachWithIndex { List<Number> column, int c ->
      if (column == null) {
        throw new IllegalArgumentException("Correlation heatmap data column $c is null")
      }
      if (column.size() != nRows) {
        throw new IllegalArgumentException("Correlation heatmap data columns must have equal lengths; expected $nRows values but column $c has ${column.size()} values")
      }
    }
  }
```

The auto-series overload (`addSeries(String, List<String>)`) builds a square `size × size` list itself, so it always passes this check.

**Interfaces:**

- Backwards compatible: existing callers passing `List<Date>` still compile.
