# matrix-core 3.9.0: exact integral narrowing in `ValueConverter`

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this
> plan task-by-task inline (CLAUDE.md forbids subagents in this repository). Steps use checkbox
> (`- [ ]`) syntax for tracking. A step is only done when its test command has been run and
> recorded next to the checkbox.

**Goal:** `ValueConverter.asInteger`, `asLong`, `asShort` and `asByte` (and therefore
`ValueConverter.convert(o, Integer|Long|Short|Byte)`, `ListConverter.toIntegers/toShorts/toBytes`
and `Matrix.convert(...)`) must never silently wrap an out-of-range value or turn `NaN`/infinity
into `0`, while keeping every currently tested coercion (truncation of fractions, `true`/`false`,
`'1.2.3'` → fallback, `''` → fallback) unchanged.

**Origin:** found while reviewing `matrix-tablesaw/req/v0.4.0-fixes.md` Task 3 (`Gtable.putAt`
coercion). The Gtable fix funnels every value through `ValueConverter`, which exposed these
narrowing defects for both numeric and string input. The tablesaw plan depends on this task at
runtime (see "Consumers" below).

**Architecture:** one private helper in `ValueConverter` performs the narrowing for all four
integral targets: value → `BigDecimal` (through the existing `asBigDecimal(Number)`, which already
maps `NaN`/infinity to `null`) → `toBigInteger()` (truncation toward zero, identical to
`intValue()` for in-range input) → range check → typed result. Out-of-range input throws
`IllegalArgumentException` naming the value and the target type; `NaN`/infinity yield
`valueIfNull`, consistent with `asBigDecimal(Number)`.

**Tech Stack:** Groovy 5.1.1 (`@CompileStatic` enforced globally through
`config/groovy/compileStatic.groovy`), Java 21, JUnit Jupiter 6, `groovier-junit`.

## Reproduced defects (matrix-core 3.9.0-SNAPSHOT, 2026-09-17)

| # | Call | Actual | Expected |
| --- | --- | --- | --- |
| 1 | `asInteger(3_000_000_000L)` | `-1294967296` (wraps) | `IllegalArgumentException` |
| 2 | `asInteger('3000000000')` | `-1294967296` (wraps) | `IllegalArgumentException` |
| 3 | `asShort(70000)` / `asShort('70000')` | `4464` (wraps) | `IllegalArgumentException` |
| 4 | `asByte(200)` / `asByte('200')` | `-56` (wraps) | `IllegalArgumentException` |
| 5 | `asLong(new BigDecimal('1e30'))` | wrapped `long` | `IllegalArgumentException` |
| 6 | `asInteger(Double.NaN)` / `asLong(Double.NaN)` | `0` | `null` (`valueIfNull`) |
| 7 | `asInteger(Double.POSITIVE_INFINITY)` | `Integer.MAX_VALUE` | `null` (`valueIfNull`) |

Rows 1–5 come from `Number.intValue()/longValue()/shortValue()/byteValue()` (JLS narrowing
wraps). Rows 6–7 come from the JLS `double → int` rule (`NaN` → `0`, infinity → `MAX_VALUE`).

## Design decisions (resolved)

- **Out of range throws; it does not become `null`.** Unparseable text (`'abc'`) becomes
  `valueIfNull` because there is no value; an out-of-range number *is* a value that cannot be
  represented, and returning `NA` would hide real data loss inside a `Matrix.convert` over a whole
  column. `IllegalArgumentException` is what the rest of matrix uses for rejected numeric input
  (`Stat`, `matrix-stats` `UnitRoot`, `matrix-tablesaw` `BigDecimalColumn.toBigDecimal` for
  infinities). `asCharacter` returns `valueIfNull` for an out-of-range code point; that method
  answers "is this a character", so it is left as is.
- **`NaN` and infinities map to `valueIfNull`**, matching `asBigDecimal(Number)` (tested in
  `ValueConverterTest.testAsBigDecimalSpecialValues`).
- **Fractions are still truncated toward zero** (`asInteger(485163.999)` → `485163`, tested). Rounding
  is `asIntegerRound`'s job. `BigDecimal.toBigInteger()` truncates toward zero exactly like
  `intValue()` does for in-range values, so no tested result changes.
- **`asLong(String)` keeps its strict `new BigDecimal(text)` parse** (it throws
  `NumberFormatException` on garbage today; harmonising it with `asInteger`'s `null` is a separate
  decision and out of scope).
- **No new public API.** The helper is `private static`; the public signatures and their default
  parameters are unchanged.

```groovy
  /**
   * Narrows a number to an integral value in {@code [min, max]} by truncating any fraction toward
   * zero (the same result {@code intValue()} gives for in-range input) and then checking the range.
   *
   * @param value the value to narrow
   * @param min the smallest representable value of the target type
   * @param max the largest representable value of the target type
   * @param targetName the target type name used in the error message
   * @return the integral part, or {@code null} when the value is NaN or infinite
   * @throws IllegalArgumentException if the integral part lies outside {@code [min, max]}
   */
  private static BigInteger integralInRange(Number value, long min, long max, String targetName) {
    BigDecimal decimal = asBigDecimal(value)
    if (decimal == null) {
      return null
    }
    BigInteger integral = decimal.toBigInteger()
    if (integral < BigInteger.valueOf(min) || integral > BigInteger.valueOf(max)) {
      throw new IllegalArgumentException("Value $value is out of range for $targetName ($min..$max)")
    }
    integral
  }

  /**
   * Converts a value to {@link Byte}. Numbers and numeric strings are truncated toward zero;
   * {@code true}/{@code false} become {@code 1}/{@code 0}; {@code null}, an empty string, an
   * unparseable string, {@code NaN} and infinities return {@code valueIfNull}.
   *
   * @param o the value to convert
   * @param valueIfNull the value returned when there is nothing to convert
   * @return the converted byte, or {@code valueIfNull}
   * @throws IllegalArgumentException if the value lies outside the {@code Byte} range
   */
  static Byte asByte(Object o, Byte valueIfNull = null) {
    if (o == null || '' == o) {
      return valueIfNull
    }
    Number number = o instanceof Number ? o : asInteger(o)
    BigInteger integral = number == null ? null : integralInRange(number, Byte.MIN_VALUE, Byte.MAX_VALUE, 'Byte')
    integral == null ? valueIfNull : integral.byteValue()
  }

  /**
   * Converts a value to {@link Short}. Numbers and numeric strings are truncated toward zero;
   * {@code true}/{@code false} become {@code 1}/{@code 0}; {@code null}, an empty string, an
   * unparseable string, {@code NaN} and infinities return {@code valueIfNull}.
   *
   * @param o the value to convert
   * @param valueIfNull the value returned when there is nothing to convert
   * @return the converted short, or {@code valueIfNull}
   * @throws IllegalArgumentException if the value lies outside the {@code Short} range
   */
  static Short asShort(Object o, Short valueIfNull = null) {
    if (o == null || '' == o) {
      return valueIfNull
    }
    Number number = o instanceof Number ? o : asInteger(o)
    BigInteger integral = number == null ? null : integralInRange(number, Short.MIN_VALUE, Short.MAX_VALUE, 'Short')
    integral == null ? valueIfNull : integral.shortValue()
  }
```

`asInteger`:

```groovy
  /**
   * Converts a value to {@link Integer}. Numbers are truncated toward zero; {@code true}/{@code false}
   * (and the strings {@code 'true'}/{@code 'false'}) become {@code 1}/{@code 0}; numeric strings are
   * parsed leniently through {@link #asBigDecimal(String, NumberFormat)}; {@code null}, an empty string,
   * an unparseable string, {@code NaN} and infinities return {@code valueIfNull}.
   *
   * @param o the value to convert
   * @param valueIfNull the value returned when there is nothing to convert
   * @return the converted integer, or {@code valueIfNull}
   * @throws IllegalArgumentException if the value lies outside the {@code Integer} range
   */
  static Integer asInteger(Object o, Integer valueIfNull = null) {
    if (o == null || '' == o) {
      return valueIfNull
    }
    Number number
    if (o instanceof Number) {
      number = o
    } else if (o instanceof Boolean) {
      return o ? 1 : 0
    } else {
      String strVal = String.valueOf(o).toLowerCase()
      if (strVal == TRUE_TEXT) {
        return 1
      } else if (strVal == FALSE_TEXT) {
        return 0
      }
      number = asBigDecimal(strVal)
    }
    BigInteger integral = number == null ? null : integralInRange(number, Integer.MIN_VALUE, Integer.MAX_VALUE, 'Integer')
    integral == null ? valueIfNull : integral.intValue()
  }
```

`asLong`:

```groovy
  /**
   * Converts a value to {@link Long}. Numbers are truncated toward zero; strings are parsed with
   * {@code new BigDecimal(text)} (a {@code NumberFormatException} for non-numeric text, as before);
   * {@code null}, an empty string, {@code NaN} and infinities return {@code valueIfNull}.
   *
   * @param o the value to convert
   * @param valueIfNull the value returned when there is nothing to convert
   * @return the converted long, or {@code valueIfNull}
   * @throws IllegalArgumentException if the value lies outside the {@code Long} range
   */
  static Long asLong(Object o, Long valueIfNull = null) {
    if (o == null || '' == o) {
      return valueIfNull
    }
    Number number = o instanceof Number ? o : new BigDecimal(String.valueOf(o))
    BigInteger integral = integralInRange(number, Long.MIN_VALUE, Long.MAX_VALUE, 'Long')
    integral == null ? valueIfNull : integral.longValue()
  }
```

Notes for the implementer:
- `asBigDecimal(Number)` returns `null` for `NaN`/infinity and otherwise `num as BigDecimal`; for
  `AtomicInteger`/`AtomicLong` and other exotic `Number`s Groovy's `as BigDecimal` goes through
  `toString()`, which is what the old `intValue()` path effectively did too.
- `integral < BigInteger.valueOf(min)` is Groovy's `compareTo` operator on `BigInteger`; under
  `@CompileStatic` it compiles to `compareTo`, no boxing surprises.
- `asByte`/`asShort` previously called `asInteger(o)` for non-`Number` input and then narrowed with
  `byteValue()`/`shortValue()`; that path now range-checks against the *byte/short* range, which is
  why `asShort('70000')` throws instead of wrapping.
- The `asInteger` `Boolean` branch and the `'true'`/`'false'` strings return before the helper, so
  `asByte(true)` / `asShort('false')` keep returning `1`/`0` through `asInteger`.
- Leave `asCharacter` untouched. (`asIntegerRound` was also left untouched here; the PR review
  follow-up below routes it through the same guard — see Task 3.)
