### 1. Make the `FileUtil` helpers honour their contract for jar-packaged resources

**Files:**
- Modify: `matrix-datasets/src/main/groovy/se/alipsa/matrix/datasets/util/FileUtil.groovy:17-38, 85-113`
- Create: `matrix-datasets/src/test/groovy/datasets/util/FileUtilTest.groovy`
- Modify: `matrix-datasets/release.md`

**Evidence (2026-09-11, same code run on two classpaths):**

| call | from `build/classes` (what `:matrix-datasets:test` sees) | from `matrix-datasets-2.2.1-SNAPSHOT.jar` (what a consumer sees) |
|---|---|---|
| `checkFilePath('/data/mtcars.csv')` | returns the `File` | throws `java.nio.file.FileSystemNotFoundException` (message `null`) |
| `getResourcePath('/data/mtcars.csv')` | `/…/build/resources/main/data/mtcars.csv` | `file:/…/matrix-datasets-2.2.1-SNAPSHOT.jar!/data/mtcars.csv` — not a file-system path; **kept as-is and documented** (no contract exists and no path can exist for a jar entry) |
| `getResourceFile('/data/mtcars.csv')` | existing `File` | a `File` whose `exists()` is `false` |
| `getResourcePath('/tmp/c++_data…/a+b.csv')` | `/tmp/c  _data…/a b.csv` (wrong) | same |

Root causes:
1. `getResourceUrl()` returns a `jar:file:…!/data/x.csv` URL for a packaged resource. `Paths.get(URI)` throws
   `FileSystemNotFoundException` for the `jar` scheme, which is not in the `catch (URISyntaxException | IllegalArgumentException |
   UnsupportedOperationException)` list, so it escapes `checkFilePath` undocumented. (`matrix-spreadsheet`'s copy catches
   `RuntimeException` and does not have this leak.)
2. `getResourcePath()` returns `URLDecoder.decode(url.getFile(), enc)`. For a jar URL `getFile()` is the string
   `file:/x.jar!/entry`, which is not a file-system path. `getResourcePath` itself has no documented contract, so that
   return value is treated as a limitation and only documented (see fix strategy). `getResourceFile()`, however, wraps it
   in a `File` and returns it without checking `exists()`, contradicting its own `@throws FileNotFoundException if the
   resource cannot be found` — that is the defect.
3. `URLDecoder` implements `application/x-www-form-urlencoded`, where `+` means space. File URLs keep a literal `+`
   in paths, so any directory or file name containing `+` is corrupted.
4. `getResourceFile()` builds its result as `new File(decodedUrlFile)`. On Windows `URL.getFile()` is `/C:/dir/x`, which
   `java.io.File` normalises to `\C:\dir\x` and resolves drive-relative (`C:\C:\dir\x`), so the returned `File` does not
   exist there either. (Reasoned from `WinNTFileSystem` semantics — not executed on Windows in this review; `checkFilePath`
   already uses the portable `Paths.get(url.toURI()).toFile()` route.)

**Fix strategy (API unchanged, including `throws` clauses):** keep all four public signatures exactly as declared today
(`checkFilePath ... throws FileNotFoundException`, `getResourceFile ... throws FileNotFoundException`,
`getResourcePath ... throws UnsupportedEncodingException`). In `checkFilePath` and `getResourceFile` add a `file`-protocol
check so a resource that exists but is not on the file system produces the documented `FileNotFoundException` with an
explanatory message (instead of a `FileSystemNotFoundException` or a dangling `File`); `getResourceFile` also verifies
`exists()` before returning. In the shared decoder escape `+` as `%2B` before `URLDecoder.decode` so form-decoding cannot
turn it into a space while the `encoding` parameter keeps its meaning for `getResourcePath`. `getResourceFile` resolves the
`File` through `Paths.get(url.toURI()).toFile()` — the same portable route `checkFilePath` uses — instead of `new File(decodedString)`,
which fixes root cause 4; its `encodingOpt` parameter stays in the signature for source compatibility (java.net.URI decodes
file URLs itself, so the option no longer influences the result). `getResourcePath` keeps its current return value for
jar resources (the url's file part) and gains GroovyDoc saying so — throwing there would be a behaviour change without a
contract to justify it. (Materialising jar resources into temp files was considered and rejected: it silently creates files
and changes the documented meaning of "verify that the filePath exists"; callers that need bytes from a jar resource use
`getResourceUrl()`.)

**Interfaces:**
- Produces (unchanged signatures): `checkFilePath(String): File`, `getResourceUrl(String): URL`,
  `getResourceFile(String, String...): File`, `getResourcePath(String, String...): String`, with their existing `throws`
  clauses untouched. The two file-returning methods now throw `FileNotFoundException` when the resource is not on the file
  system, as their GroovyDoc already promises.

  Replace `checkFilePath`:

```groovy
  /**
   * Verify that the filePath exists on the file system and return it as a File.
   * Resources that are only available inside a jar are reported as not found, because they have no
   * file-system representation; read those through {@link #getResourceUrl(String)} instead.
   *
   * @param filePath the path + file name of the resource to find (classpath resource or absolute file path)
   * @return the File if found
   * @throws FileNotFoundException if the filePath cannot be found, or is not a file on the file system
   */
  static File checkFilePath(String filePath) throws FileNotFoundException {
    URL url = getResourceUrl(filePath)
    if (url == null) {
      throw new FileNotFoundException("$filePath does not exist")
    }
    requireFileProtocol(filePath, url)
    File file
    try {
      file = Paths.get(url.toURI()).toFile()
    } catch (URISyntaxException | IllegalArgumentException | FileSystemNotFoundException | UnsupportedOperationException e) {
      throw new FileNotFoundException("$filePath cannot be resolved to a file: ${e.message}").initCause(e)
    }
    if (!file.exists()) {
      throw new FileNotFoundException("$filePath does not exist")
    }
    file
  }

  /**
   * Throws if the url does not point into the file system (e.g. a jar: url).
   */
  private static void requireFileProtocol(String name, URL url) throws FileNotFoundException {
    if (url.protocol != FILE_PROTOCOL) {
      throw new FileNotFoundException(
          "$name was found but is not a file on the file system ($url); read it via getResourceUrl() instead")
    }
  }
```

  Replace `getResourceFile` and `getResourcePath`:

```groovy
  /**
   * Gets a reference to a file or folder in the classpath or on the file system. Useful for getting test resources and
   * other similar artifacts.
   *
   * @param name the name of the resource, use / to separate path entities.
   *                    Do NOT lead with a "/" unless you know what you are doing.
   * @param encodingOpt retained for source compatibility; file urls are decoded by java.net.URI, so it is not used.
   * @return The resource as a file.
   * @throws FileNotFoundException if the resource cannot be found, or is not a file on the file system (e.g. inside a jar)
   */
  @SuppressWarnings('UnusedMethodParameter')
  static File getResourceFile(String name, String... encodingOpt) throws FileNotFoundException {
    URL url = getResourceUrl(name)
    if (url == null) {
      throw new FileNotFoundException("Resource not found: $name")
    }
    requireFileProtocol(name, url)
    File file
    try {
      // resolve through the URI, not new File(url.file): on Windows url.file is /C:/x which File treats as drive-relative
      file = Paths.get(url.toURI()).toFile()
    } catch (URISyntaxException | IllegalArgumentException | FileSystemNotFoundException | UnsupportedOperationException e) {
      throw new FileNotFoundException("Resource $name cannot be resolved to a file: ${e.message}").initCause(e)
    }
    if (!file.exists()) {
      throw new FileNotFoundException("Resource $name does not exist ($file)")
    }
    file
  }

  /**
   * Returns the decoded path part of the resource url. For a resource on the file system this is the absolute path.
   * For a resource inside a jar it is the jar url's file part, e.g. {@code file:/lib/x.jar!/data/x.csv}, which is
   * <b>not</b> a file-system path; use {@link #getResourceFile(String, String...)} if a File is required.
   *
   * @param name the name of the resource, use / to separate path entities.
   * @param encodingOpt optional encoding used to decode percent-escapes, default UTF-8.
   * @return the decoded path of the resource url
   * @throws FileNotFoundException if the resource cannot be found (undeclared, as before — Groovy does not enforce checked exceptions)
   * @throws UnsupportedEncodingException if the encoding is not supported
   */
  static String getResourcePath(String name, String... encodingOpt) throws UnsupportedEncodingException {
    URL url = getResourceUrl(name)
    if (url == null) {
      throw new FileNotFoundException("Resource not found: $name")
    }
    decodePath(url, encodingOpt)
  }

  /**
   * Percent-decodes the file part of the url. URLDecoder implements form decoding where '+' means space,
   * so a literal '+' (legal in file names and url paths) is escaped first to keep it intact.
   */
  private static String decodePath(URL url, String... encodingOpt) throws UnsupportedEncodingException {
    String encoding = encodingOpt.length > 0 ? encodingOpt[0] : DEFAULT_ENCODING
    URLDecoder.decode(url.file.replace(PLUS, ENCODED_PLUS), encoding)
  }
```

**Why:**
- `overview()` returns the cached instance itself (`Rdatasets.groovy:53`), so `Rdatasets.overview().drop('Title')` or
  `.convert(...)` corrupts the cache for every later `fetchData`/`fetchInfo`/`search` in the JVM.
- `url.openStream()` (inside `MatrixBuilder.data(String)`) and `resultList[0].toURL().text` have no connect/read timeout;
  a stalled connection hangs the caller for ever, and because `overview()` holds the class monitor while fetching, every
  other `Rdatasets` call blocks behind it.
- `URL.getText()` decodes with the JVM default charset; the Rdatasets index has 19 non-ASCII titles and the doc pages are UTF-8.
- The two-arg `fetchData`/`fetchInfo` reject `''` but accept `'  '` (`isEmpty()`), the single-arg overload uses `isBlank()`;
  the check is duplicated verbatim.
- `d.Package == "$packageName"` wraps a `String` in a GString for no reason.

**Compatibility (patch release):**
- Public signatures unchanged. No new public members: the timeouts are private constants.
- `fetchData(packageName, itemName)` names the matrix after the item. Today the name is derived from the CSV file name by
  `MatrixBuilder.data(URL)`; every CSV URL in the index has the form `csv/<Package>/<Item>.csv`, so the two are identical.
  `overview()` keeps the name `datasets` (derived from `datasets.csv` today).
- Exception types are preserved: `overview()` wraps `IOException` in `UncheckedIOException` (as today); `fetchData`/`fetchInfo`
  let `IOException` propagate (as today — Groovy does not enforce checked exceptions). A non-200 response for the selected
  csv/documentation page becomes an `IOException` — today `openStream()` throws `FileNotFoundException` (an `IOException`)
  for a 404, so the class is the same; a non-200 response while loading the index is wrapped by `overview()` into
  `UncheckedIOException`, exactly as an index `IOException` is today.
- **No `throws` clause is added to any public method.** `fetchData`/`fetchInfo` declare none today; adding
  `throws IOException` would be source-incompatible for Java callers and changes reflection-visible metadata. The
  `IOException` is documented with `@throws` in GroovyDoc only. Private helpers may declare `throws`.
- The HTTP helpers are tested deterministically against a local `com.sun.net.httpserver.HttpServer` (JDK built-in, no new
  dependency). The helpers stay `private`; the test calls them through Groovy's dynamic dispatch, which can invoke private
  static methods (verified 2026-09-11 with `Dataset.resolveMapDataFile`), so no API is added for testability.

```groovy
package se.alipsa.matrix.datasets

import groovy.transform.CompileDynamic
import groovy.transform.CompileStatic

import org.jsoup.Jsoup

import se.alipsa.matrix.core.Matrix
import se.alipsa.matrix.core.util.Logger

import java.net.http.HttpClient
import java.net.http.HttpRequest
import java.net.http.HttpResponse
import java.time.Duration

/**
 * Convenience wrapper for accessing datasets from the [R datasets repository](https://vincentarelbundock.github.io/Rdatasets/).
 * Rdatasets is a collection of more than 3,600 datasets which were originally distributed alongside the
 * statistical software environment R and some of its add-on packages.
 * <p>
 * All remote access uses a 15 second connect timeout and a 120 second request timeout. Two kinds of remote failure
 * are reported, depending on which request failed:
 * <ul>
 *   <li>loading the dataset index — {@link UncheckedIOException} from {@link #overview()} and {@link #search}, and from
 *       {@link #fetchData} / {@link #fetchInfo} when they are the first call while the cache is cold (after their
 *       argument validation, which throws {@link IllegalArgumentException} before any network access);</li>
 *   <li>fetching the selected csv or documentation page ({@link #fetchData} / {@link #fetchInfo}) — {@link IOException}.</li>
 * </ul>
 */
@CompileStatic
class Rdatasets {

  private static final Logger log = Logger.getLogger(Rdatasets)

  private static final Duration CONNECT_TIMEOUT = Duration.ofSeconds(15)
  private static final Duration REQUEST_TIMEOUT = Duration.ofSeconds(120)
  private static final String OVERVIEW_URL = 'https://raw.githubusercontent.com/vincentarelbundock/Rdatasets/master/datasets.csv'
  private static final String OVERVIEW_NAME = 'datasets'
  private static final String COMMA = ','
  private static final String QUOTE = '"'
  private static final String NULL_OR_BLANK_MSG = 'Package name and item name cannot be null or blank'
  private static final int EXPECTED_PARTS = 2
  private static final int HTTP_OK = 200

  private static final HttpClient HTTP_CLIENT = HttpClient.newBuilder()
      .connectTimeout(CONNECT_TIMEOUT)
      .followRedirects(HttpClient.Redirect.NORMAL)
      .build()

  private static volatile Matrix cachedOverview = null

  /**
   * Returns an overview of the datasets available in the R datasets repository.
   * The overview includes columns for Package, Item, Title, CSV URL, and html url.
   * The index is fetched on first call and cached; each call returns an independent copy so callers may
   * freely convert, filter or rename columns without affecting later calls. Use {@link #refresh()} to re-fetch.
   *
   * @return a Matrix containing the overview of datasets
   * @throws UncheckedIOException if the remote data cannot be fetched
   */
  static Matrix overview() {
    Matrix result = cachedOverview
    if (result == null) {
      synchronized (Rdatasets) {
        result = cachedOverview
        if (result == null) {
          try {
            result = fetchCsv(OVERVIEW_URL, OVERVIEW_NAME)
          } catch (IOException e) {
            throw new UncheckedIOException("Failed to fetch Rdatasets overview: ${e.message}", e)
          }
          cachedOverview = result
        }
      }
    }
    result.clone()
  }

  /**
   * Clears the cached overview so the next call to {@link #overview()} re-fetches the data.
   */
  static void refresh() {
    cachedOverview = null
  }

  /**
   * Fetches the documentation for a specific dataset from the R datasets repository.
   * The documentation is returned as a String, and can be converted to plain text if desired.
   *
   * @param packageName the name of the package containing the dataset (column Package in the overview)
   * @param itemName the name of the dataset (column Item in the overview)
   * @param toPlainText if true, converts HTML content to plain text (default is false)
   * @return the documentation for the specified dataset
   * @throws IllegalArgumentException if a name is null or blank, or the dataset does not exist
   * @throws UncheckedIOException if the dataset index has to be loaded first and that fails (see {@link #overview()})
   * @throws IOException if the documentation page cannot be fetched (network failure, timeout or non-200 response)
   */
  @CompileDynamic
  static String fetchInfo(String packageName, String itemName, boolean toPlainText = false) {
    requireNames(packageName, itemName)
    log.debug("Fetching info for $packageName/$itemName (plainText=$toPlainText)")
    def urlResult = GQ {
      from d in overview()
      where d.Package == packageName && d.Item == itemName
      select d.Doc
    }
    def resultList = urlResult.toList()
    if (resultList.isEmpty()) {
      log.warn("Dataset not found: $packageName/$itemName")
      throw new IllegalArgumentException("Dataset not found: $packageName/$itemName")
    }
    String content = fetchText(resultList[0] as String)
    if (toPlainText) {
      content = Jsoup.parse(content).wholeText()
    }
    log.debug("Successfully fetched info for $packageName/$itemName")
    content
  }

  /**
   * Fetches the data for a specific dataset from the R datasets repository.
   * The data is returned as a Matrix object named after the item, with all columns as String.
   *
   * @param packageName the name of the package containing the dataset (column Package in the overview)
   * @param itemName the name of the dataset (column Item in the overview)
   * @return a Matrix containing the data for the specified dataset
   * @throws IllegalArgumentException if a name is null or blank, or the dataset does not exist
   * @throws UncheckedIOException if the dataset index has to be loaded first and that fails (see {@link #overview()})
   * @throws IOException if the csv cannot be fetched (network failure, timeout or non-200 response)
   */
  @CompileDynamic
  static Matrix fetchData(String packageName, String itemName) {
    requireNames(packageName, itemName)
    log.debug("Fetching data for $packageName/$itemName")
    def urlResult = GQ {
      from d in overview()
      where d.Package == packageName && d.Item == itemName
      select d.CSV
    }
    def resultList = urlResult.toList()
    if (resultList.isEmpty()) {
      log.warn("Dataset not found: $packageName/$itemName")
      throw new IllegalArgumentException("Dataset not found: $packageName/$itemName")
    }
    Matrix result = fetchCsv(resultList[0] as String, itemName)
    log.debug("Successfully fetched $packageName/$itemName: ${result.rowCount()} rows, ${result.columnCount()} columns")
    result
  }

  // fetchData(String packageSlashItem) and search(String text) stay exactly as they are today.

  /**
   * Validates that both names are present.
   */
  private static void requireNames(String packageName, String itemName) {
    if (packageName == null || packageName.isBlank() || itemName == null || itemName.isBlank()) {
      throw new IllegalArgumentException(NULL_OR_BLANK_MSG)
    }
  }

  /**
   * Downloads a csv document and parses it into a Matrix.
   *
   * @param url the csv location
   * @param name the matrixName to assign
   * @return the parsed matrix
   * @throws IOException on any transport error, timeout or non-200 response
   */
  private static Matrix fetchCsv(String url, String name) throws IOException {
    String csv = fetchText(url)
    Matrix.builder()
        .matrixName(name)
        .csvString(csv, [delimiter: COMMA, quoteString: QUOTE, lineComment: ''])
        .build()
  }

  /**
   * Performs a GET request with connect and request timeouts and returns the body as text.
   * The body is decoded with the charset from the Content-Type header, falling back to UTF-8.
   *
   * @param url the location to fetch
   * @param timeout the request timeout, default {@link #REQUEST_TIMEOUT} (overridable for tests)
   * @return the response body
   * @throws IOException on transport errors, timeouts, interruption or a non-200 status
   */
  private static String fetchText(String url, Duration timeout = REQUEST_TIMEOUT) throws IOException {
    HttpRequest request = HttpRequest.newBuilder(URI.create(url))
        .timeout(timeout)
        .GET()
        .build()
    HttpResponse<String> response
    try {
      response = HTTP_CLIENT.send(request, HttpResponse.BodyHandlers.ofString())
    } catch (InterruptedException e) {
      Thread.currentThread().interrupt()
      throw new IOException("Interrupted while fetching $url", e)
    }
    if (response.statusCode() != HTTP_OK) {
      throw new IOException("HTTP ${response.statusCode()} when fetching $url")
    }
    response.body()
  }

}
```

## Deferred — behaviour or API changes, not for a patch release

### D1. Derive `mapData()` prefix matching from the real map names (finding 12)

**Current behaviour (`Dataset.groovy:33-40, 257-262`):** non-exact lookup walks a hand-written table
`[co: county, fr: france, it: italy, nz: nz, st: state, us: usa]` and accepts the first entry whose *key is a prefix of the
input* (`name.startsWith(prefix)`). Consequences, verified on 2026-09-11:

| input | today | why |
|---|---|---|
| `'fr'`, `'fra'`, `'franc'` | france | `'fra'.startsWith('fr')` |
| `'italian'`, `'stockholm'`, `'cosmos'`, `'usb'` | italy, state, county, usa — **silently** | any string beginning with a table key matches |
| `'wor'`, `'worl'`, `'wo'` | `IllegalArgumentException: no map data exists` | `world`/`world2` have no table entry |

So the abbreviation feature works for six of eight maps, and for those six it also accepts arbitrary unrelated words.
The table is a second source of truth beside `MAP_DATA_FILES` (adding a map means editing two maps), and the winning entry
depends on `LinkedHashMap` iteration order.

**Proposed rule:** an input matches when it is a prefix of **exactly one** key of `MAP_DATA_FILES` (`key.startsWith(name)`);
an exact key always wins; more than one candidate is an "ambiguous" `IllegalArgumentException` listing the candidates
(`'wor'` → `world, world2`); zero candidates is the existing "no map data exists" error; `exact = true` is unchanged.
Every input that is a genuine abbreviation keeps working (`co`, `fr`, `it`, `nz`, `st`, `us`, `usa`, …). The results that
change are accidental matches (`'italian'` → error instead of italy) and `world`-prefixes (ambiguous error instead of
"no map data"). No module in the repository calls `mapData()` with an abbreviated name (grep, 2026-09-11).

**Why deferred:** `'italian'` → italy is arguably a bug, but the fix necessarily changes which inputs resolve, i.e. observable
behaviour of a public method, and the current behaviour is what the GroovyDoc ("allows prefix matching") loosely describes.
Implementation sketch and tests: replace `resolveMapDataFile` with a `findAll { key.startsWith(name) }` over
`MAP_DATA_FILES.keySet()`, delete `MAP_DATA_PREFIXES`, add tests for `'fr'`, `'FRA'`, `'wor'` (ambiguous), `'italian'` (no match),
`'fr'` with `exact = true`.

### D2. Convert `mtcars.vs` to `Integer` (finding 13)

In R's `mtcars`, `vs` (engine shape, 0 = V, 1 = straight) and `am` (transmission, 0 = automatic, 1 = manual) are both 0/1
indicators. The loader converts `am`, `cyl`, `gear`, `carb` to `Integer` but `vs` to `BigDecimal` (`Dataset.groovy:109`), so
`mtcars.type('vs') == BigDecimal` while `mtcars.type('am') == Integer` — frequency tables, group-by keys and chart scales
treat the two columns differently. Nothing in the repository depends on `vs` being `BigDecimal` (grep, 2026-09-11).

**Why deferred:** the type of a returned column is part of the module's contract; changing it can break a consumer that
does `(BigDecimal) row['vs']` or asserts `type('vs')`. One-line change (`vs: Integer`) plus a test asserting
`mtcars.type('vs') == Integer` and `Stat.sum(mtcars['vs']) == 14 as BigDecimal`.

### D3. Stop using the deprecated `java.net.URL(String)` in `Dataset.fromUrl()` (finding 7)

`new URL(String)` is deprecated since JDK 20 (JDK-8294241) because it neither validates nor escapes its input; the
replacement `URI.create(s).toURL()` is what `MatrixBuilder.data(String)` already does, so `fromUrl` could pass the string
straight through. **Why deferred:** for a malformed input (e.g. an unescaped space) the failure moves from a late
`MalformedURLException`/connection error to an early `URISyntaxException`/`IllegalArgumentException` — a change in failure
mode, and the deprecation produces no warning under the Groovy compiler. No functional bug for valid URLs.
