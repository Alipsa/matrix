# Matrix-pict 0.6.0 Additional Charts Implementation Plan

> **For agentic workers:** Per `CLAUDE.md`, execute this plan **inline** with `superpowers:executing-plans` (do NOT dispatch subagents). Steps use checkbox (`- [ ]`) syntax for tracking. A checkbox is only marked done after the listed test command has been run successfully and recorded next to the task.

**Goal:** Add `HeatmapChart`, `CorrelationHeatmapChart` and `RadarChart` to `matrix-pict`, plus a generic per-series colour override (`seriesColors`) usable by every pict chart type.

**Architecture:** Each new chart is a `Chart<T>` subclass with a fluent `Builder` and a non-deprecated `create(...)` factory, following the existing pict pattern (`PieChart`, `BubbleChart`). Rendering is delegated to Charm through new `CharmBridge` branches: heatmaps map to `TileBuilder` (+ optional `TextBuilder` value labels) with a continuous fill scale; the radar is laid out by the bridge itself in Cartesian space (rings, spokes, polygons, spoke labels) because Charm trains positional scales *after* the polar coordinate transform, which makes `POLAR` unusable for fixed theta/radius domains. `CorrelationHeatmapChart extends HeatmapChart` so tile rendering, value labels and colour overrides are shared. Series colours live in `Style` and are applied as a Charm `Scale.manual(...)` on both `color` and `fill`.

**Tech Stack:** Groovy 5.1.1, JDK 21, JUnit Jupiter 6.0.3 + `groovier-junit`, Charm (`matrix-charts`), `matrix-stats` `Correlation`, gsvg.

**Spec:** The design was agreed in conversation on 2026-09-19 and is summarised in the *Design Summary* section below; this document is both spec and plan.

## Design Summary

### Public API (package `se.alipsa.matrix.pict`)

| Class | Builder methods (in addition to inherited `ChartBuilder` ones) | Factory |
|---|---|---|
| `HeatmapChart` | `rowLabels(String)`, `columns(String...)`, `columns(List<String>)`, `showValues(boolean)` (default `true`), `colors(Color low, Color high)`, `colors(Color low, Color mid, Color high, Number midpoint = null)` | `create(String title, Matrix data, String rowLabelColumn, List<String> columns)` and `create(String title, Matrix data, List<String> columns)` |
| `CorrelationHeatmapChart extends HeatmapChart` | `columns(...)`, `method(String)` (default `Correlation.PEARSON`; accepts `SPEARMAN`, `KENDALL`), `showValues`, `colors(...)` | `create(String title, Matrix data, List<String> columns, String method = Correlation.PEARSON)` |
| `RadarChart` | `label(String)`, `values(String...)`, `values(List<String>)`, `normalize(boolean)` (default `false`), `fillAlpha(Number)` (default `0.4`) | `create(String title, Matrix data, String labelColumn, List<String> valueColumns, boolean normalize = false)` |
| `Chart.ChartBuilder` (all charts) | `seriesColors(Color...)`, `seriesColors(List<Color>)`, `seriesColors(Map<String, Color>)` | `Style.seriesColors` / `Style.seriesColorMap` |

Unsupported inherited builder methods throw `IllegalArgumentException` with message `"<ChartName> does not support <method>(...)"`:
- Heatmap/Correlation: `x`, `y`, `xAxisTitle`, `yAxisTitle`, `xAxisScale`, `yAxisScale`, `yLabels`.
- Radar: `x`, `y`, `xAxisTitle`, `yAxisTitle`, `xAxisScale`, `yLabels`. `yAxisScale` is **kept** and sets the radial range.

### Semantics
- Heatmap: each selected column is an x category (in the given order); each matrix row is a y category labelled by the `rowLabels` column, or `1..n` when omitted; the first matrix row is drawn at the top. An empty matrix is rejected. `null` cells — and `NaN`/infinite `Double`/`Float` cells, which `ListConverter.toBigDecimals` turns into `null` — are kept and rendered with Charm's NA colour (`#999999`) without a value label. Values are stored column-major in `values[c][r]` as `BigDecimal`.
- Correlation: coefficients from `Correlation.cor(colA, colB, method)`, rounded `HALF_UP` to 2 decimals; diagonal is `1.00`; `null` (zero variance) becomes `0.00`; symmetric half computed once and mirrored. Fill scale limits fixed to `[-1, 1]` (honoured by a small Charm change in Task 4: `ColorCharmScale` continuous domains now respect `Scale.params['limits']`, so an all-positive correlation matrix still maps `0` to the mid colour); default diverging palette low `#B2182B`, mid `#F7F7F7`, high `#2166AC`, midpoint `0`. Legend title defaults to the method name. Selected columns must contain no `null`s.
- Radar: one polygon per matrix row (rows are grouped by an internal row index, so duplicate labels still give distinct polygons that share a legend entry and colour); `axisLabels` = value columns (≥ 3 required); `seriesLabels` = `row[labelColumn].toString()`; values as `BigDecimal`; `null` and negative values rejected; empty matrix rejected. `normalize(true)` min-max scales each **column** to `[0, 1]` at build time (constant column → `0`). Radial range is `[0, max]` with 4 evenly spaced rings unless `yAxisScale` is set, in which case `start` must be `0`, `end` is the outer radius (every plotted value must be `<= end`, otherwise `IllegalArgumentException`) and one ring is drawn per `step`. Values are never clamped.
- Series colours: the bridge resolves a colour for **every** series name of the chart, in order: `seriesColorMap[name]`, else `seriesColors[index]`, else Charm's default discrete palette entry for that index (`ColorScaleUtil.defaultPalette(n)` in matrix-charts — the same `DEFAULT_COLORS` list with `idx % size` wraparound that `Scale.discrete()` uses). The result is passed as a complete `Scale.manual(Map)` on `color` and `fill`, so partial maps and short lists never fall into Charm's NA grey. Applies to any chart with a discrete series/fill mapping (multi-series Line/Area/Bar/Scatter, grouped Bubble, Pie, Radar). For **single-series** Line/Area/Bar/Scatter/Bubble and for Histogram (whose series name is its value column, or `Histogram.DEFAULT_SERIES_NAME` = `'values'` for the list factory) the resolved colour of that one series is applied as the layer's literal colour. BoxChart maps `fill` to the category so each box takes the colour resolved for its category name. Heatmaps ignore `seriesColors` (continuous fill; use `colors(...)`).
- Heatmap `colors(low, mid, high)` without a midpoint places `mid` at the centre of the fill domain (`Scale.gradientN`); with a midpoint it uses `Scale.gradient(low, high, mid, midpoint)`.

### Radar rendering (why not `coord POLAR`)
`CharmRenderer.trainScales` runs the full per-layer pipeline — including `CoordEngine.apply`, which turns polar `(theta, r)` into Cartesian `(r·cos, r·sin)` — *before* `ScaleEngine.train`. Positional scales and the theta axis are therefore trained on Cartesian output, so fixing the x scale to `[0, 1]` and y to `[0, max]` would misplace every polygon. The bridge instead computes the layout in a unit circle: rings (`PathBuilder`, closed), spokes (`SegmentBuilder`), one `PolygonBuilder` layer for the data, and `TextBuilder` spoke labels, on a Cartesian coord with axes and panel grid hidden and limits `[-1.25, 1.25]`. `applyLabelsAndTheme` gets an `applyScales` flag so the user's `yAxisScale` is consumed as the radial range instead of being written to the y scale.

### Heatmap tile sizing
`TileRenderer` draws 10×10 px tiles unless `xmin/xmax/ymin/ymax` are mapped. The bridge therefore uses continuous index axes (`x = c`, `xmin = c − 0.5`, `xmax = c + 0.5`; `y = rows − 1 − r`, `ymin/ymax` likewise) with breaks at the indices and the column/row names as labels, limits `[−0.5, n − 0.5]` and `expand [0, 0]`, so adjacent tiles fill the panel.

```groovy
  /**
   * The default discrete colour palette Charm assigns to levels of a colour/fill scale
   * when no palette is configured; level {@code i} gets {@code DEFAULT_COLORS[i % size]}.
   */
  static final List<String> DEFAULT_COLORS = [
      '#1f77b4', '#d62728', '#2ca02c', '#ff7f0e', '#9467bd',
      '#8c564b', '#e377c2', '#7f7f7f', '#bcbd22', '#17becf'

  /**
   * Returns the default discrete colours for {@code n} levels in order, wrapping around
   * {@link #DEFAULT_COLORS} exactly as an unconfigured discrete scale does.
   *
   * @param n number of levels (0 or negative returns an empty list)
   * @return one hex colour per level
   */
  static List<String> defaultPalette(int n) {
    n <= 0 ? [] : (0..<n).collect { int i -> DEFAULT_COLORS[i % DEFAULT_COLORS.size()] }
```

```groovy
   * Resolves one colour per series of the chart, in series order:
   * {@code seriesColorMap[name]}, else {@code seriesColors[index]}, else Charm's
   * default discrete palette entry for that index (with wraparound). Returns {@code null} when the chart
   * configures neither, so Charm's own defaults apply untouched.
   */
  private static Map<String, String> resolveSeriesColors(Chart chart) {
    Style style = chart.style
    if (style == null || (!style.seriesColorMap && !style.seriesColors)) {
      return null
    }
    List<String> names = seriesNames(chart)
    List<String> defaults = ColorScaleUtil.defaultPalette(names.size())
    Map<String, String> resolved = [:]
    names.eachWithIndex { String name, int idx ->
      Color configured = style.seriesColorMap?.get(name)
          ?: (idx < (style.seriesColors?.size() ?: 0) ? style.seriesColors[idx] : null)
      resolved[name] = configured != null ? colorToHex(configured) : defaults[idx]
    }
    resolved
  }

  /**
   * The discrete series levels of a chart in the order they are emitted to Charm.
   */
  private static List<String> seriesNames(Chart chart) {
    switch (chart) {
      case PieChart -> chart.categorySeries.collect { Object category -> category.toString() }
      case BubbleChart -> {
        BubbleChart bubble = chart as BubbleChart
        bubble.groupSeries ? bubble.groupSeries.collect { Object group -> group.toString() }.unique()
            : (chart.valueSeriesNames ?: [])
      }
      default -> chart.valueSeriesNames ?: []
    }
  }

    Map<String, String> resolved = resolveSeriesColors(chart)
    if (resolved) {
      spec.scale.color(Scale.manual(resolved))
      spec.scale.fill(Scale.manual(resolved))
    }
  }

   * colour of the one series is applied as the layer's literal colour and fill.

  private static void applySingleSeriesColor(LayerBuilder builder, Chart chart, boolean multiSeries) {
```

```groovy
  /**
   * Ensures a column exists in the matrix.
   *
   * @param data the matrix to check
   * @param columnName the column that must exist
   * @throws IllegalArgumentException if the column is missing
   */
  static void requireColumn(Matrix data, String columnName) {
    if (columnName == null || data.columnIndex(columnName) < 0) {
      throw new IllegalArgumentException("Column '${columnName}' does not exist in ${data.matrixName ?: 'the matrix'}")
    }
  }

  /**
   * Ensures a column exists and has a numeric type.
   *
   * @param data the matrix to check
   * @param columnName the column that must exist and be numeric
   * @throws IllegalArgumentException if the column is missing or not a Number type
   */
  static void requireNumericColumn(Matrix data, String columnName) {
    requireColumn(data, columnName)
    Class type = data.type(columnName)
    if (type == null || !Number.isAssignableFrom(type)) {
      throw new IllegalArgumentException("Column '${columnName}' must be numeric, got ${type?.simpleName ?: 'null'}")
    }
  }

  /**
   * Validates a numeric column and converts it to BigDecimals, rejecting any cell that
   * is null or cannot be represented exactly ({@code NaN} and infinities convert to
   * {@code null} in {@link se.alipsa.matrix.core.ValueConverter#asBigDecimal}).
   * Use for charts whose maths cannot tolerate gaps (correlation, radar).
   *
   * @param data the matrix to read
   * @param columnName the column to convert
   * @return the column as BigDecimals, same size and order as the source column
   * @throws IllegalArgumentException if the column is missing or non-numeric, or any cell is null, NaN or infinite
   */
  static List<BigDecimal> completeNumericColumn(Matrix data, String columnName) {
    requireNumericColumn(data, columnName)
    List<?> raw = data.column(columnName)
    List<BigDecimal> converted = ListConverter.toBigDecimals(raw)
    int bad = converted.findIndexOf { BigDecimal value -> value == null }
    if (bad >= 0) {
      throw new IllegalArgumentException("Column '${columnName}' contains a null, NaN or infinite value at row ${bad} (${raw[bad]}); complete numeric data is required")
    }
    converted
  }
```

```groovy
package se.alipsa.matrix.pict

import se.alipsa.matrix.core.ListConverter
import se.alipsa.matrix.core.Matrix

import java.awt.Color

/**
 * Heatmap chart: a grid of coloured tiles where each selected matrix column is an
 * x category, each matrix row is a y category, and the cell colour encodes the
 * numeric value.
 *
 * <p>Usage via fluent builder:
 * <pre>{@code
 * HeatmapChart chart = HeatmapChart.builder(data)
 *     .title('Quarterly sales')
 *     .rowLabels('region')
 *     .columns('q1', 'q2', 'q3')
 *     .colors(Color.WHITE, Color.RED)
 *     .build()
 * Plot.png(chart, new File('heatmap.png'))
 * }</pre>
 *
 * <p>Row labels default to {@code 1..n} when {@code rowLabels} is not set. Null cells
 * are kept and rendered with the NA colour. Values are stored column-major in
 * {@link #getValues()} so {@code values[c][r]} is column {@code c}, row {@code r}.</p>
 */
class HeatmapChart extends Chart<HeatmapChart> {

  /** X categories, i.e. the selected column names in order. */
  List<String> columnLabels = []

  /** Y categories: the row label column values, or 1..n when no row label column was given. */
  List<?> rowLabels = []

  /** Cell values, column-major: {@code values[columnIndex][rowIndex]}. */
  List<List<BigDecimal>> values = []

  /** Whether to print each cell's value on its tile. Default {@code true}. */
  boolean showValues = true

  /** Low end of the fill gradient, or {@code null} for the Charm default. */
  Color lowColor

  /** Optional midpoint colour of the fill gradient; when {@code null} a two-colour gradient is used. */
  Color midColor

  /** High end of the fill gradient, or {@code null} for the Charm default. */
  Color highColor

  /** Data value at which {@link #midColor} applies; {@code null} lets Charm pick the midpoint. */
  BigDecimal midpoint

  /** Fixed fill-scale limits {@code [min, max]}, or {@code null} to derive them from the data. */
  List<BigDecimal> fillLimits

  /**
   * Creates a heatmap from a matrix using a row label column.
   *
   * @param title chart title
   * @param data source matrix
   * @param rowLabelColumn column providing y-axis labels (must not also be a value column)
   * @param columns numeric columns that become the x categories, in order
   * @return the heatmap chart
   * @throws IllegalArgumentException if a column is missing, non-numeric, or the row label column is also a value column
   */
  static HeatmapChart create(String title, Matrix data, String rowLabelColumn, List<String> columns) {
    HeatmapChart chart = new HeatmapChart()
    populate(chart, title, data, rowLabelColumn, columns)
    chart
  }

  /**
   * Creates a heatmap from a matrix with row labels {@code 1..n}.
   *
   * @param title chart title
   * @param data source matrix
   * @param columns numeric columns that become the x categories, in order
   * @return the heatmap chart
   * @throws IllegalArgumentException if a column is missing or non-numeric
   */
  static HeatmapChart create(String title, Matrix data, List<String> columns) {
    create(title, data, null, columns)
  }

  /**
   * Fills the chart from the given matrix. Shared by the factory methods and the builder.
   */
  protected static void populate(HeatmapChart chart, String title, Matrix data, String rowLabelColumn, List<String> columns) {
    if (columns == null || columns.isEmpty()) {
      throw new IllegalArgumentException('Heatmap requires at least one value column')
    }
    if (data.rowCount() == 0) {
      throw new IllegalArgumentException("Heatmap data ${data.matrixName ?: ''} has no rows".trim())
    }
    columns.each { String column -> requireNumericColumn(data, column) }
    if (rowLabelColumn != null) {
      requireColumn(data, rowLabelColumn)
      if (columns.contains(rowLabelColumn)) {
        throw new IllegalArgumentException("The row label column '${rowLabelColumn}' cannot also be a value column")
      }
    }
    chart.title = title
    chart.columnLabels = new ArrayList<String>(columns)
    chart.rowLabels = rowLabelColumn == null
        ? (1..data.rowCount()).toList()
        : data.column(rowLabelColumn) as List<?>
    chart.values = columns.collect { String column -> ListConverter.toBigDecimals(data.column(column)) }
    chart.categorySeries = chart.rowLabels
    chart.valueSeries = chart.values as List<List<?>>
    chart.valueSeriesNames = chart.columnLabels
  }

  /**
   * Creates a new fluent builder for a {@link HeatmapChart}.
   *
   * @param data the matrix containing the values
   * @return a new builder
   */
  static Builder builder(Matrix data) { new Builder(data) }

  /**
   * Fluent builder for {@link HeatmapChart}. Axis-oriented builder methods
   * ({@code x}, {@code y}, axis titles, axis scales, {@code yLabels}) are not
   * applicable and throw {@link IllegalArgumentException}.
   */
  static class Builder extends HeatmapBuilder<Builder, HeatmapChart> {

    Builder(Matrix data) { super(data) }

    /**
     * Builds the configured {@link HeatmapChart}.
     *
     * @return the heatmap
     * @throws IllegalStateException if {@code columns(...)} was not called
     */
    @Override
    HeatmapChart build() {
      if (selectedColumns == null) {
        throw new IllegalStateException('columns(...) must be called before build()')
      }
      HeatmapChart chart = new HeatmapChart()
      populate(chart, title, data, rowLabelColumn, selectedColumns)
      applyTo(chart)
      applyHeatmapOptions(chart)
      chart
    }

  }

  /**
   * Shared builder base for heatmap-style charts. Holds the selected columns, row
   * label column, value-label toggle and gradient colours, and rejects axis methods.
   *
   * @param <B> concrete builder type
   * @param <C> concrete chart type
   */
  abstract static class HeatmapBuilder<B extends HeatmapBuilder, C extends HeatmapChart> extends Chart.ChartBuilder<B, C> {

    protected String rowLabelColumn
    protected List<String> selectedColumns
    protected boolean showValues = true
    protected Color lowColor
    protected Color midColor
    protected Color highColor
    protected BigDecimal midpoint

    protected HeatmapBuilder(Matrix data) { super(data) }

    /**
     * Sets the column whose values label the y axis.
     *
     * @param columnName row label column
     * @return this builder
     */
    B rowLabels(String columnName) { rowLabelColumn = columnName; this as B }

    /**
     * Selects the numeric value columns (x categories, in order).
     *
     * @param columnNames at least one column name
     * @return this builder
     * @throws IllegalArgumentException if no column is given
     */
    B columns(String... columnNames) {
      if (columnNames == null || columnNames.length == 0) {
        throw new IllegalArgumentException('columns(...) requires at least one column')
      }
      selectedColumns = columnNames.toList()
      this as B
    }

    /**
     * Selects the numeric value columns (x categories, in order).
     *
     * @param columnNames at least one column name
     * @return this builder
     * @throws IllegalArgumentException if the list is null or empty
     */
    B columns(List<String> columnNames) {
      if (columnNames == null || columnNames.isEmpty()) {
        throw new IllegalArgumentException('columns(...) requires at least one column')
      }
      selectedColumns = new ArrayList<String>(columnNames)
      this as B
    }

    /**
     * Toggles printing of cell values on the tiles (default {@code true}).
     *
     * @param show whether to print values
     * @return this builder
     */
    B showValues(boolean show) { showValues = show; this as B }

    /**
     * Sets a two-colour fill gradient.
     *
     * @param low colour for the lowest value
     * @param high colour for the highest value
     * @return this builder
     */
    B colors(Color low, Color high) {
      lowColor = low
      midColor = null
      highColor = high
      midpoint = null
      this as B
    }

    /**
     * Sets a three-colour (diverging) fill gradient.
     *
     * @param low colour for the lowest value
     * @param mid colour at the midpoint
     * @param high colour for the highest value
     * @param midpointValue data value that maps to {@code mid}; {@code null} lets Charm choose (default)
     * @return this builder
     */
    B colors(Color low, Color mid, Color high, Number midpointValue = null) {
      lowColor = low
      midColor = mid
      highColor = high
      midpoint = midpointValue == null ? null : midpointValue as BigDecimal
      this as B
    }

    /** Copies the heatmap-specific options onto the chart. */
    protected void applyHeatmapOptions(C chart) {
      chart.showValues = showValues
      chart.lowColor = lowColor
      chart.midColor = midColor
      chart.highColor = highColor
      chart.midpoint = midpoint
    }

    @Override B x(String columnName) { throw unsupported('x') }
    @Override B y(String columnName) { throw unsupported('y') }
    @Override B y(String... columnNames) { throw unsupported('y') }
    @Override B xAxisTitle(String title) { throw unsupported('xAxisTitle') }
    @Override B yAxisTitle(String title) { throw unsupported('yAxisTitle') }
```

```groovy
  /**
   * Overrides the trained domain ends with {@code params['limits']} = [lower, upper]
   * when present; a {@code null} end keeps the data-derived value, and reversed limits
   * are ordered (min/max swapped) exactly as {@code ScaleEngine} does for positional
   * scales. Values outside the limits are clamped by the gradient functions.
   */
  private void applyLimits() {
    List limits = scaleSpec?.params?.get('limits') as List
    if (limits == null || limits.size() < 2) {
      return
    }
    BigDecimal lower = ValueConverter.asBigDecimal(limits[0])
    BigDecimal upper = ValueConverter.asBigDecimal(limits[1])
    if (lower == null && upper == null) {
      return
    }
    BigDecimal candidateMin = lower != null ? lower : domainMin
    BigDecimal candidateMax = upper != null ? upper : domainMax
    domainMin = candidateMin.min(candidateMax)
    domainMax = candidateMin.max(candidateMax)
  }
```

```groovy
  private static PlotSpec buildHeatmapSpec(HeatmapChart chart) {
    int columnCount = chart.columnLabels.size()
    int rowCount = chart.rowLabels.size()
    List<List<?>> rows = []
    chart.columnLabels.eachWithIndex { String column, int c ->
      chart.rowLabels.eachWithIndex { Object rowLabel, int r ->
        BigDecimal value = chart.values[c][r]
        BigDecimal x = c
        BigDecimal y = rowCount - 1 - r   // first matrix row at the top
        rows << [x, x - HALF, x + HALF, y, y - HALF, y + HALF, value, value == null ? null : value.toPlainString()]
      }
    }
    Matrix data = Matrix.builder()
        .columnNames(AES_X, AES_XMIN, AES_XMAX, AES_Y, AES_YMIN, AES_YMAX, AES_VALUE, COL_TEXT)
        .rows(rows)
        .types([BigDecimal, BigDecimal, BigDecimal, BigDecimal, BigDecimal, BigDecimal, BigDecimal, String])
        .build()

    PlotSpec spec = Charts.plot(data)
    spec.mapping([
        (AES_X): AES_X, (AES_XMIN): AES_XMIN, (AES_XMAX): AES_XMAX,
        (AES_Y): AES_Y, (AES_YMIN): AES_YMIN, (AES_YMAX): AES_YMAX,
        (AES_FILL): AES_VALUE
    ])
    spec.addLayer(new TileBuilder())
    if (chart.showValues) {
      spec.addLayer(new TextBuilder().mapping([(AES_LABEL): COL_TEXT]))
    }
    spec.scale.x(indexScale(chart.columnLabels*.toString()))
    spec.scale.y(indexScale(chart.rowLabels.reverse()*.toString()))
    spec.scale.fill(heatmapFillScale(chart))
    applyLabelsAndTheme(spec, chart)
    spec
  }

  /**
   * Continuous scale over 0..n-1 with one break per index labelled by the given names,
   * no expansion, so tiles with xmin/xmax = index ± 0.5 fill the panel edge to edge.
   */
  private static Scale indexScale(List<String> labels) {
    Scale scale = Scale.continuous()
    scale.params['limits'] = [-HALF, labels.size() - HALF]
    scale.params['expand'] = [0, 0]
    scale.breaks = (0..<labels.size()).collect { int i -> i as BigDecimal }
    scale.labels = labels
    scale
  }

  /**
   * Builds the continuous fill scale for a heatmap from the chart's optional
   * low/mid/high colours, midpoint and fixed limits.
   */
  private static Scale heatmapFillScale(HeatmapChart chart) {
    Scale scale
    String low = colorToHex(chart.lowColor) ?: DEFAULT_GRADIENT_LOW
    String high = colorToHex(chart.highColor) ?: DEFAULT_GRADIENT_HIGH
    if (chart.midColor != null && chart.midpoint != null) {
      scale = Scale.gradient(low, high, colorToHex(chart.midColor), chart.midpoint)
    } else if (chart.midColor != null) {
      // Charm's gradient only uses `mid` when a midpoint is given; gradientN places the
      // middle stop at the centre of the domain, which is the documented behaviour.
      scale = Scale.gradientN([low, colorToHex(chart.midColor), high])
    } else if (chart.lowColor != null || chart.highColor != null) {
      scale = Scale.gradient(
          colorToHex(chart.lowColor) ?: DEFAULT_GRADIENT_LOW,
          colorToHex(chart.highColor) ?: DEFAULT_GRADIENT_HIGH
      )
    } else {
      scale = Scale.gradient()
    }
    if (chart.fillLimits) {
      scale.params['limits'] = chart.fillLimits
    }
    scale
  }
```

```groovy
package se.alipsa.matrix.pict

import se.alipsa.matrix.core.Matrix
import se.alipsa.matrix.stats.Correlation

import java.awt.Color
import java.math.RoundingMode

/**
 * Correlation heatmap: computes the pairwise correlation matrix of the selected
 * numeric columns (Pearson by default; Spearman and Kendall supported) and renders it
 * as a {@link HeatmapChart} with a diverging colour scale fixed to {@code [-1, 1]}.
 *
 * <p>Usage:
 * <pre>{@code
 * CorrelationHeatmapChart chart = CorrelationHeatmapChart.builder(whisky)
 *     .title('Whisky flavour correlations')
 *     .columns('Body', 'Sweetness', 'Smoky', 'Medicinal')
 *     .method(Correlation.SPEARMAN)   // default is Correlation.PEARSON
 *     .build()
 * Plot.png(chart, new File('corr.png'))
 * }</pre>
 *
 * <p>Coefficients are rounded half-up to two decimals. The diagonal is always
 * {@code 1.00}; an undefined coefficient (zero-variance column) is shown as
 * {@code 0.00}. Selected columns must be complete: null, {@code NaN} and infinite cells are rejected.</p>
 */
class CorrelationHeatmapChart extends HeatmapChart {

  /** Default colour for a correlation of -1. */
  static final Color DEFAULT_LOW = new Color(0xB2, 0x18, 0x2B)

  /** Default colour for a correlation of 0. */
  static final Color DEFAULT_MID = new Color(0xF7, 0xF7, 0xF7)

  /** Default colour for a correlation of +1. */
  static final Color DEFAULT_HIGH = new Color(0x21, 0x66, 0xAC)

  /** Supported correlation method names. */
  static final List<String> METHODS = [Correlation.PEARSON, Correlation.SPEARMAN, Correlation.KENDALL].asImmutable()

  private static final int SCALE = 2
  private static final List<BigDecimal> CORRELATION_LIMITS = [-1.00, 1.00].asImmutable()

  /** The correlation method used ({@code pearson}, {@code spearman} or {@code kendall}). */
  String method = Correlation.PEARSON

  CorrelationHeatmapChart() {
    lowColor = DEFAULT_LOW
    midColor = DEFAULT_MID
    highColor = DEFAULT_HIGH
    midpoint = 0
    fillLimits = CORRELATION_LIMITS
  }

  /**
   * Creates a correlation heatmap for the given numeric columns.
   *
   * @param title chart title
   * @param data source matrix
   * @param columns numeric columns to correlate (at least one)
   * @param method {@link Correlation#PEARSON} (default), {@link Correlation#SPEARMAN} or {@link Correlation#KENDALL}
   * @return the chart
   * @throws IllegalArgumentException if a column is missing, non-numeric, contains null/NaN/infinite cells, or the method is unknown
   */
  static CorrelationHeatmapChart create(String title, Matrix data, List<String> columns, String method = Correlation.PEARSON) {
    CorrelationHeatmapChart chart = new CorrelationHeatmapChart()
    populateCorrelation(chart, title, data, columns, method)
    chart
  }

  private static void populateCorrelation(CorrelationHeatmapChart chart, String title, Matrix data, List<String> columns, String method) {
    if (columns == null || columns.isEmpty()) {
      throw new IllegalArgumentException('Correlation heatmap requires at least one column')
    }
    if (!METHODS.contains(method)) {
      throw new IllegalArgumentException("Unknown correlation method '${method}', expected one of ${METHODS}")
    }
    List<List<BigDecimal>> series = columns.collect { String column -> completeNumericColumn(data, column) }
    chart.title = title
    chart.method = method
    chart.columnLabels = new ArrayList<String>(columns)
    chart.rowLabels = new ArrayList<String>(columns)
    chart.values = correlationMatrix(series, method)
    chart.categorySeries = chart.rowLabels
    chart.valueSeries = chart.values as List<List<?>>
    chart.valueSeriesNames = chart.columnLabels
  }

  /**
   * Computes the column-major correlation matrix. Only the upper triangle is
   * calculated; the lower triangle mirrors it.
   */
  private static List<List<BigDecimal>> correlationMatrix(List<List<BigDecimal>> series, String method) {
    int n = series.size()
    List<List<BigDecimal>> corr = (0..<n).collect { new ArrayList<BigDecimal>(Collections.nCopies(n, (BigDecimal) null)) }
    BigDecimal one = BigDecimal.ONE.setScale(SCALE, RoundingMode.HALF_UP)
    for (int c = 0; c < n; c++) {
      corr[c][c] = one
      for (int r = c + 1; r < n; r++) {
        BigDecimal value = Correlation.cor(series[c], series[r], method)
        BigDecimal rounded = (value ?: BigDecimal.ZERO).setScale(SCALE, RoundingMode.HALF_UP)
        corr[c][r] = rounded
        corr[r][c] = rounded
      }
    }
    corr
  }

  /**
   * Creates a new fluent builder for a {@link CorrelationHeatmapChart}.
   *
   * @param data the matrix with the columns to correlate
   * @return a new builder
   */
  static Builder builder(Matrix data) { new Builder(data) }

  /**
   * Fluent builder for {@link CorrelationHeatmapChart}. Inherits {@code columns},
   * {@code showValues} and {@code colors} from the heatmap builder; {@code rowLabels}
   * is not applicable because both axes are the selected columns.
   */
  static class Builder extends HeatmapChart.HeatmapBuilder<Builder, CorrelationHeatmapChart> {

    private String method = Correlation.PEARSON

    Builder(Matrix data) { super(data) }

    /**
     * Sets the correlation method.
     *
     * @param method {@link Correlation#PEARSON} (default), {@link Correlation#SPEARMAN} or {@link Correlation#KENDALL}
     * @return this builder
     * @throws IllegalArgumentException if the method is not one of {@link #METHODS}
     */
    Builder method(String method) {
      if (!METHODS.contains(method)) {
        throw new IllegalArgumentException("Unknown correlation method '${method}', expected one of ${METHODS}")
      }
      this.method = method
      this
    }

    /**
     * Not supported: both axes of a correlation heatmap are the selected columns.
     *
     * @param columnName ignored
     * @return never returns
     * @throws IllegalArgumentException always
     */
    @Override
    Builder rowLabels(String columnName) {
      throw new IllegalArgumentException('CorrelationHeatmapChart does not support rowLabels(...)')
    }

    /**
     * Builds the configured {@link CorrelationHeatmapChart}.
     *
     * @return the chart
     * @throws IllegalStateException if {@code columns(...)} was not called
     */
    @Override
    CorrelationHeatmapChart build() {
      if (selectedColumns == null) {
        throw new IllegalStateException('columns(...) must be called before build()')
      }
      CorrelationHeatmapChart chart = new CorrelationHeatmapChart()
      populateCorrelation(chart, title, data, selectedColumns, method)
      applyTo(chart)
      chart.showValues = showValues
      if (lowColor != null || midColor != null || highColor != null) {
        chart.lowColor = lowColor ?: DEFAULT_LOW
        chart.midColor = midColor ?: DEFAULT_MID
        chart.highColor = highColor ?: DEFAULT_HIGH
        chart.midpoint = midpoint ?: 0
      }
      chart
    }

  }

}
```

```groovy
package se.alipsa.matrix.pict

import se.alipsa.matrix.core.Matrix

/**
 * Radar (spider) chart: each selected numeric column is a spoke and each matrix row
 * is drawn as a closed polygon whose vertices are the row's values on those spokes.
 *
 * <p>Usage:
 * <pre>{@code
 * RadarChart chart = RadarChart.builder(cars)
 *     .title('Car profiles')
 *     .label('model')                                  // one polygon per row, named by this column
 *     .values('speed', 'power', 'range', 'comfort')    // at least 3 numeric columns
 *     .normalize(true)                                 // optional per-column min-max scaling to [0, 1]
 *     .fillAlpha(0.3)                                  // optional polygon fill opacity, default 0.4
 *     .seriesColors([Alpha: Color.RED, Beta: Color.BLUE])
 *     .build()
 * Plot.png(chart, new File('radar.png'))
 * }</pre>
 *
 * <p>Values must be {@code >= 0} (a radar radiates from the centre). The radial range is
 * {@code [0, max]} of the plotted values unless a {@code yAxisScale} is provided, in which
 * case {@code start} must be {@code 0} and every value must be {@code <= end}; values are
 * never clamped. With {@code normalize(true)} every column is min-max scaled to {@code [0, 1]}
 * independently (negative input is allowed in that mode); a constant column maps to {@code 0}.</p>
 */
class RadarChart extends Chart<RadarChart> {

  /** Minimum number of spokes needed to draw a polygon. */
  static final int MIN_AXES = 3

  /** Default polygon fill opacity. */
  static final BigDecimal DEFAULT_FILL_ALPHA = 0.4

  /** Number of grid rings drawn when no radial scale is configured. */
  static final int DEFAULT_RINGS = 4

  /** Spoke names: the selected value columns in order. */
  List<String> axisLabels = []

  /** One label per polygon, taken from the label column. */
  List<String> seriesLabels = []

  /** Plotted values: {@code seriesValues[seriesIndex][axisIndex]}. Already normalized when {@link #normalized} is true. */
  List<List<BigDecimal>> seriesValues = []

  /** Whether {@link #seriesValues} were min-max scaled per column to [0, 1]. */
  boolean normalized = false

  /** Polygon fill opacity in [0, 1]. */
  BigDecimal fillAlpha = DEFAULT_FILL_ALPHA

  /**
   * Creates a radar chart with one polygon per matrix row.
   *
   * @param title chart title
   * @param data source matrix
   * @param labelColumn column providing the polygon (series) names
   * @param valueColumns at least three numeric columns, one per spoke
   * @param normalize when true, min-max scale each column to [0, 1] (default {@code false})
   * @return the chart
   * @throws IllegalArgumentException if fewer than three value columns are given, a column is missing or
   *         non-numeric, a value cell is null/NaN/infinite, the matrix is empty, or (without {@code normalize}) a value is negative
   */
  static RadarChart create(String title, Matrix data, String labelColumn, List<String> valueColumns, boolean normalize = false) {
    RadarChart chart = new RadarChart()
    populate(chart, title, data, labelColumn, valueColumns, normalize)
    chart
  }

  /**
   * Largest plotted value across all series, or {@code 1} when every value is {@code <= 0}.
   * Used as the default outer radius.
   *
   * @return the radial maximum
   */
  BigDecimal maxValue() {
    BigDecimal max = seriesValues.collect { List<BigDecimal> values -> values.max() }.max()
    max == null || max <= 0 ? 1 : max
  }

  /**
   * Outer radius of the chart: {@code yAxisScale.end} when a radial scale is set, else {@link #maxValue()}.
   *
   * @return the data value drawn at the outer ring
   */
  BigDecimal outerRadius() {
    validateRadialScale()
    yAxisScale != null ? yAxisScale.end : maxValue()
  }

  /**
   * Data values at which grid rings are drawn: every {@code step} up to {@code end} when a
   * radial scale is set, else four evenly spaced rings up to {@link #maxValue()}.
   *
   * @return ascending ring radii in data units
   */
  List<BigDecimal> ringValues() {
    BigDecimal outer = outerRadius()
    if (yAxisScale == null) {
      return (1..DEFAULT_RINGS).collect { int ring -> outer * ring / DEFAULT_RINGS }
    }
    List<BigDecimal> rings = []
    BigDecimal current = yAxisScale.step
    while (current < outer) {
      rings << current
      current += yAxisScale.step
    }
    rings << outer
    rings
  }

  /**
   * Ensures a configured radial scale starts at zero (a radar always radiates from the
   * centre) and covers every plotted value; values are never clamped.
   *
   * @throws IllegalArgumentException if {@code yAxisScale.start != 0} or any value exceeds {@code yAxisScale.end}
   */
  void validateRadialScale() {
    if (yAxisScale == null) {
      return
    }
    if (yAxisScale.start != 0) {
      throw new IllegalArgumentException("Radar yAxisScale start must be 0, got ${yAxisScale.start}")
    }
    BigDecimal max = maxValue()
    if (max > yAxisScale.end) {
      throw new IllegalArgumentException("Radar value ${max} exceeds yAxisScale end ${yAxisScale.end}")
    }
  }

  private static void populate(RadarChart chart, String title, Matrix data, String labelColumn, List<String> valueColumns, boolean normalize) {
    if (valueColumns == null || valueColumns.size() < MIN_AXES) {
      throw new IllegalArgumentException("Radar chart requires at least ${MIN_AXES} value columns, got ${valueColumns?.size() ?: 0}")
    }
    if (data.rowCount() == 0) {
      throw new IllegalArgumentException("Radar data ${data.matrixName ?: ''} has no rows".trim())
    }
    requireColumn(data, labelColumn)
    List<List<BigDecimal>> columns = valueColumns.collect { String column -> completeNumericColumn(data, column) }
    if (normalize) {
      columns = columns.collect { List<BigDecimal> column -> normalizeColumn(column) }
    } else {
      columns.eachWithIndex { List<BigDecimal> column, int i ->
        if (column.any { BigDecimal value -> value < 0 }) {
          throw new IllegalArgumentException("Column '${valueColumns[i]}' contains negative values; radar values must be >= 0 (use normalize(true) for signed data)")
        }
      }
    }
    int rowCount = data.rowCount()
    chart.title = title
    chart.axisLabels = new ArrayList<String>(valueColumns)
    chart.seriesLabels = data.column(labelColumn).collect { Object label -> String.valueOf(label) }
    chart.seriesValues = (0..<rowCount).collect { int r -> columns.collect { List<BigDecimal> column -> column[r] } }
    chart.normalized = normalize
    chart.categorySeries = chart.axisLabels
    chart.valueSeries = chart.seriesValues as List<List<?>>
    chart.valueSeriesNames = chart.seriesLabels
  }

  /**
   * Min-max scales a column to [0, 1]; a constant column becomes all zeros.
   */
  private static List<BigDecimal> normalizeColumn(List<BigDecimal> column) {
    BigDecimal min = column.min()
    BigDecimal max = column.max()
    BigDecimal range = max - min
    column.collect { BigDecimal value -> range == 0 ? 0.0 : (value - min) / range }
  }

  /**
   * Creates a new fluent builder for a {@link RadarChart}.
   *
   * @param data the matrix with one row per polygon
   * @return a new builder
   */
  static Builder builder(Matrix data) { new Builder(data) }

  /**
   * Fluent builder for {@link RadarChart}. {@code x}, {@code y}, axis titles,
   * {@code xAxisScale} and {@code yLabels} are not applicable and throw
   * {@link IllegalArgumentException}; {@code yAxisScale} sets the radial range.
   */
  static class Builder extends Chart.ChartBuilder<Builder, RadarChart> {

    private String labelColumn
    private List<String> valueColumns
    private boolean normalize = false
    private BigDecimal fillAlpha = DEFAULT_FILL_ALPHA

    Builder(Matrix data) { super(data) }

    /**
     * Sets the column that names each polygon.
     *
     * @param columnName label column
     * @return this builder
     */
    Builder label(String columnName) { labelColumn = columnName; this }

    /**
     * Selects the spoke columns (at least three, numeric).
     *
     * @param columnNames value column names in spoke order
     * @return this builder
     */
    Builder values(String... columnNames) { valueColumns = columnNames == null ? null : columnNames.toList(); this }

    /**
     * Selects the spoke columns (at least three, numeric).
     *
     * @param columnNames value column names in spoke order
     * @return this builder
     */
    Builder values(List<String> columnNames) { valueColumns = columnNames == null ? null : new ArrayList<String>(columnNames); this }

    /**
     * Enables per-column min-max normalization to [0, 1] (default {@code false}).
     *
     * @param enabled whether to normalize
     * @return this builder
     */
    Builder normalize(boolean enabled) { normalize = enabled; this }

    /**
     * Sets the polygon fill opacity (default {@code 0.4}).
     *
     * @param alpha opacity in [0, 1]
     * @return this builder
     * @throws IllegalArgumentException if alpha is outside [0, 1]
     */
    Builder fillAlpha(Number alpha) {
      BigDecimal value = alpha as BigDecimal
      if (value == null || value < 0 || value > 1) {
        throw new IllegalArgumentException("fillAlpha must be between 0 and 1, got ${alpha}")
      }
      fillAlpha = value
      this
    }

    @Override Builder x(String columnName) { throw unsupported('x') }
    @Override Builder y(String columnName) { throw unsupported('y') }
    @Override Builder y(String... columnNames) { throw unsupported('y') }
    @Override Builder xAxisTitle(String title) { throw unsupported('xAxisTitle') }
    @Override Builder yAxisTitle(String title) { throw unsupported('yAxisTitle') }
    @Override Builder xAxisScale(AxisScale scale) { throw unsupported('xAxisScale') }
    @Override Builder xAxisScale(BigDecimal start, BigDecimal end, BigDecimal step) { throw unsupported('xAxisScale') }
    @Override Builder yLabels(Map<String, String> labels) { throw unsupported('yLabels') }

    private static IllegalArgumentException unsupported(String method) {
      new IllegalArgumentException("RadarChart does not support ${method}(...)")
    }

    /**
     * Builds the configured {@link RadarChart}.
     *
     * @return the chart
     * @throws IllegalStateException if {@code label(...)} or {@code values(...)} was not called
     */
    @Override
    RadarChart build() {
      if (labelColumn == null) {
        throw new IllegalStateException('label(...) must be called before build()')
      }
      if (valueColumns == null) {
        throw new IllegalStateException('values(...) must be called before build()')
      }
      RadarChart chart = new RadarChart()
      populate(chart, title, data, labelColumn, valueColumns, normalize)
      applyTo(chart)
      chart.fillAlpha = fillAlpha
      chart.validateRadialScale()
      chart
    }

  }

}
```

```groovy
  private static final String AES_YEND = 'yend'
  private static final String COL_ROW = 'row'
  private static final BigDecimal RADAR_LABEL_RADIUS = 1.12
  private static final BigDecimal RADAR_LIMIT = 1.25
  private static final String RADAR_GRID_COLOR = '#cccccc'
  private static final String NO_FILL = 'none'

  private static PlotSpec buildRadarSpec(RadarChart chart) {
    int axisCount = chart.axisLabels.size()
    BigDecimal outer = chart.outerRadius()
    // Spoke i sits at 12 o'clock rotated clockwise by i/n of a turn.
    List<BigDecimal> angles = (0..<axisCount).collect { int i -> PI / 2 - (i / axisCount) * 2 * PI }

    Matrix polygonData = radarPolygonData(chart, angles, outer)
    Matrix ringData = radarRingData(chart.ringValues(), angles, outer)
    Matrix spokeData = radarSpokeData(angles)
    Matrix labelData = radarLabelData(chart.axisLabels, angles)

    PlotSpec spec = Charts.plot(polygonData)
    spec.mapping([(AES_X): AES_X, (AES_Y): AES_Y, (AES_GROUP): COL_ROW, (AES_COLOR): AES_SERIES, (AES_FILL): AES_SERIES])
    spec.addLayer(new PathBuilder().data(ringData).inheritMapping(false)
        .mapping([(AES_X): AES_X, (AES_Y): AES_Y, (AES_GROUP): AES_GROUP])
        .color(RADAR_GRID_COLOR))
    spec.addLayer(new SegmentBuilder().data(spokeData).inheritMapping(false)
        .mapping([(AES_X): AES_X, (AES_Y): AES_Y, (AES_XEND): AES_XEND, (AES_YEND): AES_YEND])
        .color(RADAR_GRID_COLOR))
    spec.addLayer(new PolygonBuilder().alpha(chart.fillAlpha))
    spec.addLayer(new TextBuilder().data(labelData).inheritMapping(false)
        .mapping([(AES_X): AES_X, (AES_Y): AES_Y, (AES_LABEL): COL_TEXT]))

    spec.scale.x(unitScale())
    spec.scale.y(unitScale())
    applyLabelsAndTheme(spec, chart, false)
    se.alipsa.matrix.charm.ThemeSpec theme = spec.theme as se.alipsa.matrix.charm.ThemeSpec
    hideAxes(theme, true, true)
    theme.panelGridMajor = null
    theme.panelGridMinor = null
    theme.explicitNulls.addAll(['panelGridMajor', 'panelGridMinor'])
    spec
  }

  /** One row per (series, spoke): unit-circle x/y, the series label for colour/legend, and the row index for grouping. */
  private static Matrix radarPolygonData(RadarChart chart, List<BigDecimal> angles, BigDecimal outer) {
    List<List<?>> rows = []
    chart.seriesValues.eachWithIndex { List<BigDecimal> values, int s ->
      String series = chart.seriesLabels[s]
      angles.eachWithIndex { BigDecimal angle, int i ->
        BigDecimal r = values[i] / outer
        rows << [r * angle.cos(), r * angle.sin(), series, "row${s}".toString()]
      }
    }
    Matrix.builder()
        .columnNames(AES_X, AES_Y, AES_SERIES, COL_ROW)
        .rows(rows)
        .types([BigDecimal, BigDecimal, String, String])
        .build()
  }

  /** One closed path per ring (first vertex repeated), radius = ringValue / outer. */
  private static Matrix radarRingData(List<BigDecimal> ringValues, List<BigDecimal> angles, BigDecimal outer) {
    List<List<?>> rows = []
    ringValues.eachWithIndex { BigDecimal ringValue, int ring ->
      BigDecimal r = ringValue / outer
      String group = "ring${ring}".toString()
      (angles + [angles[0]]).each { BigDecimal angle -> rows << [r * angle.cos(), r * angle.sin(), group] }
    }
    Matrix.builder()
        .columnNames(AES_X, AES_Y, AES_GROUP)
        .rows(rows)
        .types([BigDecimal, BigDecimal, String])
        .build()
  }

  /** One segment per spoke from the centre to the unit circle. */
  private static Matrix radarSpokeData(List<BigDecimal> angles) {
    List<List<?>> rows = angles.collect { BigDecimal angle -> [0.0, 0.0, angle.cos(), angle.sin()] as List<?> }
    Matrix.builder()
        .columnNames(AES_X, AES_Y, AES_XEND, AES_YEND)
        .rows(rows)
        .types([BigDecimal, BigDecimal, BigDecimal, BigDecimal])
        .build()
  }

  /** Spoke names just outside the unit circle. */
  private static Matrix radarLabelData(List<String> axisLabels, List<BigDecimal> angles) {
    List<List<?>> rows = []
    angles.eachWithIndex { BigDecimal angle, int i ->
      rows << [RADAR_LABEL_RADIUS * angle.cos(), RADAR_LABEL_RADIUS * angle.sin(), axisLabels[i]]
    }
    Matrix.builder()
        .columnNames(AES_X, AES_Y, COL_TEXT)
        .rows(rows)
        .types([BigDecimal, BigDecimal, String])
        .build()
  }

  private static Scale unitScale() {
    Scale scale = Scale.continuous()
    scale.params['limits'] = [-RADAR_LIMIT, RADAR_LIMIT]
    scale.params['expand'] = [0, 0]
    scale
  }
```

Notes for the implementer:
- `LayerBuilder.inheritMapping(false)` + `mapping(Map)` keeps the ring/spoke/label layers out of the `series` colour mapping, so they take the literal `color(...)`; `PathRenderer` always emits `fill="none"`.
- `GeomUtils.groupSeries` keys on `datum.group` first, so grouping by `row` guarantees one polygon per matrix row even when labels repeat; `color`/`fill` still map to the label for the legend and `seriesColors`.
- `resolveFill` prefers `layer.params.fill` over the fill scale, which is why the data polygon layer sets no literal fill — it must take the mapped series colour.
- The text layer has no `color` mapping, so it renders in the default text colour.

````markdown
### HeatmapChart

A grid of coloured tiles. Each selected column becomes an x category, each matrix row a y category, and the cell colour encodes the value. Cell values are printed on the tiles by default.

```groovy
import se.alipsa.matrix.pict.HeatmapChart
import java.awt.Color

def sales = Matrix.builder().data(
    region: ['North', 'South', 'East'],
    q1: [10, 20, 30],
    q2: [15, 25, 35],
    q3: [12, 22, 40]
).types(String, Integer, Integer, Integer).build()

def chart = HeatmapChart.builder(sales)
    .title('Quarterly sales')
    .rowLabels('region')              // y labels; defaults to 1..n when omitted
    .columns('q1', 'q2', 'q3')        // x categories, in order (numeric columns)
    .colors(Color.WHITE, Color.RED)   // optional two-colour gradient
    .showValues(true)                 // default true
    .build()

Plot.png(chart, new File('heatmap.png'))
```

| Builder method | Description | Default |
|---|---|---|
| `rowLabels(String)` | Column whose values label the y axis | `1..n` |
| `columns(String...)` / `columns(List<String>)` | Numeric value columns (x categories) — required | — |
| `showValues(boolean)` | Print each value on its tile | `true` |
| `colors(Color low, Color high)` | Two-colour fill gradient | Charm default (`#132B43` → `#56B1F7`) |
| `colors(Color low, Color mid, Color high, Number midpoint = null)` | Diverging gradient; `midpoint` is the data value drawn in `mid`; when omitted `mid` sits at the centre of the value range | — |

`x`, `y`, `xAxisTitle`, `yAxisTitle`, `xAxisScale`, `yAxisScale` and `yLabels` are not applicable and throw `IllegalArgumentException`. `null`, `NaN` and infinite cells are drawn in the NA colour (`#999999`) without a value label. `seriesColors(...)` is ignored for heatmaps — use `colors(...)`.

Factory equivalents: `HeatmapChart.create(title, data, rowLabelColumn, columns)` and `HeatmapChart.create(title, data, columns)`.

### CorrelationHeatmapChart

Computes the pairwise correlation of the selected numeric columns (via `matrix-stats` `Correlation`) and renders it as a heatmap with a diverging colour scale fixed to `[-1, 1]` (red `#B2182B` → white → blue `#2166AC`, midpoint `0`). Coefficients are rounded half-up to two decimals; the diagonal is `1.00` and an undefined coefficient (zero-variance column) is shown as `0.00`.

```groovy
import se.alipsa.matrix.pict.CorrelationHeatmapChart
import se.alipsa.matrix.stats.Correlation

def chart = CorrelationHeatmapChart.builder(whisky)
    .title('Whisky flavour correlations')
    .columns('Body', 'Sweetness', 'Smoky', 'Medicinal', 'Tobacco')
    .method(Correlation.SPEARMAN)     // PEARSON (default), SPEARMAN or KENDALL
    .legendTitle('ρ')                 // defaults to the method name
    .build()

Plot.svg(chart, new File('correlation.svg'))
```

| Builder method | Description | Default |
|---|---|---|
| `columns(String...)` / `columns(List<String>)` | Numeric columns to correlate — required; null, `NaN` and infinite cells are rejected | — |
| `method(String)` | `Correlation.PEARSON`, `SPEARMAN` or `KENDALL` | `PEARSON` |
| `showValues(boolean)` | Print coefficients on tiles | `true` |
| `colors(low, high)` / `colors(low, mid, high, midpoint)` | Override the diverging palette | red/white/blue, midpoint `0` |

Requires `matrix-stats` on the runtime classpath. Factory: `CorrelationHeatmapChart.create(title, data, columns, method = Correlation.PEARSON)`.

### RadarChart

Draws one closed polygon per matrix row over spokes defined by the selected numeric columns (at least three). Rows with the same label are still drawn as separate polygons but share a colour and legend entry.

```groovy
import se.alipsa.matrix.pict.RadarChart
import java.awt.Color

def cars = Matrix.builder().data(
    model: ['Alpha', 'Beta'],
    speed: [90, 30], power: [40, 80], range: [70, 50], comfort: [50, 90]
).types(String, Integer, Integer, Integer, Integer).build()

def chart = RadarChart.builder(cars)
    .title('Car profiles')
    .label('model')                                  // series name column — required
    .values('speed', 'power', 'range', 'comfort')    // spokes — at least 3 numeric columns
    .normalize(false)                                // true: min-max scale each column to [0, 1]
    .fillAlpha(0.4)                                  // polygon fill opacity, default 0.4
    .yAxisScale(0.0, 100.0, 25.0)                    // optional radial range; default [0, max]
    .seriesColors([Alpha: Color.RED, Beta: Color.BLUE])
    .build()

Plot.png(chart, new File('radar.png'), 600, 600)
```

| Builder method | Description | Default |
|---|---|---|
| `label(String)` | Column naming each polygon — required | — |
| `values(String...)` / `values(List<String>)` | Spoke columns (≥ 3, numeric; null, `NaN` and infinite cells rejected) — required | — |
| `normalize(boolean)` | Per-column min-max scaling to `[0, 1]`; a constant column maps to `0`. Without it every value must be `>= 0` | `false` |
| `fillAlpha(Number)` | Polygon fill opacity in `[0, 1]` | `0.4` |
| `yAxisScale(start, end, step)` | Fixed radial range: `start` must be `0`, every value must be `<= end` (never clamped), one grid ring per `step` | `[0, max value]` with 4 rings |

`x`, `y`, `xAxisTitle`, `yAxisTitle`, `xAxisScale` and `yLabels` throw `IllegalArgumentException`. Factory: `RadarChart.create(title, data, labelColumn, valueColumns, normalize = false)`.
````

````markdown
### Series Colours

Override the default palette per series, either by position or by series name:

```groovy
// by position: first colour → first y column, second → second, ...
LineChart.builder(data).x('month').y('north', 'south')
    .seriesColors(Color.RED, Color.BLUE)
    .build()

// by name (y column name, pie category, or radar row label); named entries take precedence,
// the rest fall back to the positional list, then the default palette
BarChart.builder(data).x('month').y('north', 'south')
    .seriesColors([north: Color.RED, south: Color.BLUE])
    .build()

// after build
chart.style.seriesColorMap = [north: Color.RED]
```

Resolution order per series: the named entry, else the positional entry, else the default palette colour for that position — so a partial map such as `[north: Color.RED]` colours only `north` and leaves `south` on the default palette. Applies to multi-series Line/Area/Bar/Scatter charts, grouped Bubble charts, Pie slices and Radar polygons. For a single-series chart the colour resolved for its one series is used; a `Histogram`'s series name is its value column (`seriesColors([price: Color.RED])`), or `Histogram.DEFAULT_SERIES_NAME` (`'values'`) when created from a bare list. `BoxChart` colours each box by its category name (which also adds a fill legend — hide it with `legendVisible(false)` if unwanted). Names that match no series are ignored. Heatmaps have a continuous fill and use `colors(...)` instead.
````

```markdown
## v0.6.0, unreleased

**New Chart Types**
- `HeatmapChart` — wide-format heatmap (`rowLabels`/`columns`), optional value labels
  and two- or three-colour gradient via `colors(...)`.
- `CorrelationHeatmapChart` (extends `HeatmapChart`) — Pearson (default), Spearman or
  Kendall correlation matrix via `matrix-stats`, diverging scale fixed to `[-1, 1]`,
  coefficients rounded to two decimals, legend titled by method.
- `RadarChart` — one polygon per row over ≥ 3 numeric spokes, optional per-column
  `normalize(true)`, `fillAlpha`, radial range and ring spacing via `yAxisScale`
  (`start` must be 0). Laid out by the Charm bridge in Cartesian space with rings,
  spokes and spoke labels.

**API Improvements**
- Per-series colour overrides: `seriesColors(Color...)`, `seriesColors(List<Color>)`
  and `seriesColors(Map<String, Color>)` on every chart builder, backed by
  `Style.seriesColors` / `Style.seriesColorMap`. Resolution per series is named entry →
  positional entry → default palette, so partial maps keep Charm's defaults for the rest.
  Applies to multi-series line, area, bar and scatter charts, grouped bubbles, pie slices,
  radar polygons and box charts (per category); single-series charts use their one series'
  colour, and a histogram's series name is its value column.
- `Histogram` now sets `valueSeriesNames` to its value column, or to the new
  `Histogram.DEFAULT_SERIES_NAME` (`'values'`) for the deprecated `create(List, bins)` factory. Requires matrix-charts ≥ 0.5.1 (`ColorScaleUtil.defaultPalette` and
  continuous colour-scale `limits`).
- `Chart.requireColumn(Matrix, String)`, `Chart.requireNumericColumn(Matrix, String)` and
  `Chart.completeNumericColumn(Matrix, String)` validation helpers (the last rejects null,
  `NaN` and infinite cells and returns the column as BigDecimals).

**Code Quality**
- `CharmBridge.applyLabelsAndTheme` gained an `applyScales` flag; axis hiding is now
  the shared `hideAxes(theme, x, y)` helper.
```
