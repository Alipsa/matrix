# matrix-ggplot v0.6.0 Review Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this
> plan task-by-task inline (CLAUDE.md forbids subagents in this repository). Steps use checkbox
> (`[ ]`) syntax for tracking. A step is only done when its test command has been run and
> recorded next to the checkbox.

**Goal:** Fix the findings from the 2026-09-20 review of `matrix-ggplot` (8 reproduced bugs,
4 issues, 2 suggestions), add ggplot2's `layer_data()`/`ggplot_build()` backed by the Charm
pipeline, and release as 0.6.0 rather than 0.5.1, because the fixes change rendered output for
every chart that uses `factor()`/closure aesthetics, `I()` constants, constant point colours, or
any of the currently ignored colour/shape/size scales.

**Architecture:** All rendering is delegated to Charm (`matrix-charts`) through
`se.alipsa.matrix.gg.bridge.GgCharmCompiler`. Fixes therefore live in three places: (1) the
compiler, which must stop mutating user data, route `I()` constants to layer params, and map
`linewidth`; (2) the gg scale classes, which gain `toCharmScale()` implementations that reuse
Charm's existing `Scale.viridis/stepsN/fermenter/grey/hue/identity/radius(...)` factories; (3)
`GgChart`, whose `plus(Stats)` and `parseStatType` must accept everything the enum and the DSL
already advertise. `GgStat`/`GgPosition` (3,200 LOC that Charm superseded) are deleted.

**Tech Stack:** Groovy 5.1.1 (`@CompileStatic` enforced globally through
`config/groovy/compileStatic.groovy`), Java 21, matrix-charts 0.6.0-SNAPSHOT (Charm), gsvg 1.2.0
(`se.alipsa.groovy.svg.*`), JUnit Jupiter 6, `groovier-junit`.

**Spec:** The review findings are reproduced in section "Findings being fixed" below so this
plan is self-contained.

3.3 [ ] Rewrite `Expression` evaluation. Change the field and constructors to untyped closures
and make `evaluate` return the raw value, only coercing *strings* that parse as numbers:

```groovy
  /** The closure that computes the value from row data */
  final Closure closure

  Expression(Closure closure) {
    this(closure, null)
  }

  Expression(Closure closure, String name) {
    if (closure == null) {
      throw new IllegalArgumentException('Expression closure cannot be null')
    }
    this.closure = closure
    this.name = name ?: ".expr.${NAME_COUNTER.incrementAndGet()}"
  }

  /**
   * Evaluate the expression for a single row.
   *
   * <p>Numbers, Booleans and other objects are returned as-is. A String (or GString) whose text
   * is a decimal literal is converted to a Number so that {@code "${it.x * 2}"} still maps to a
   * continuous scale; any other String is kept as a category label.</p>
   *
   * @param row the row to evaluate
   * @return the closure result, or null when the closure returns null
   * @throws RuntimeException if the closure throws an exception
   */
  @CompileDynamic
  Object evaluate(Row row) {
    try {
      def result = closure.call(row)
      if (result == null || result instanceof Number || result instanceof Boolean) {
        return result
      }
      if (result instanceof CharSequence) {
        return coerceNumericText(result.toString())
      }
      return result
    } catch (Exception e) {
      throw new RuntimeException("Expression evaluation failed for row: ${e.message}", e)
    }
  }

  private static Object coerceNumericText(String text) {
    String trimmed = text.trim()
    if (trimmed.isEmpty()) {
      return text
    }
    try {
      return trimmed.contains('.') || trimmed.contains('e') || trimmed.contains('E')
          ? new BigDecimal(trimmed)
          : new BigInteger(trimmed)
    } catch (NumberFormatException ignored) {
      return text
    }
  }

  /**
   * Evaluate the expression for all rows in a matrix.
   *
   * @param data the matrix to evaluate row by row
   * @return computed values, one per row
   */
  List<Object> evaluateAll(Matrix data) {
    List<Object> results = new ArrayList<>(data.rowCount())
    for (Row row : data) {
      results.add(evaluate(row))
    }
    results
  }
```

```groovy
   * computed statistics instead of SVG output.</p>

   * @return one entry per (panel, layer) in panel-major order, with post-pipeline {@link LayerData}

    if (chart == null) {
      throw new IllegalArgumentException('chart cannot be null')

    RenderContext context = new RenderContext(chart, config ?: new RenderConfig(), new Svg())
    context.panels = facetRenderer.computePanels(
        chart.data, chart.facet.type, chart.facet.rows, chart.facet.cols,
        chart.facet.vars, chart.facet.ncol, chart.facet.nrow, chart.facet.params
    )
    if (context.panels == null || context.panels.isEmpty()) {
      context.panels = [defaultPanel(chart.data.rowCount())]
    }
    List<LayerPanelData> result = []
    context.panels.each { PanelSpec panel ->
      chart.layers.eachWithIndex { LayerSpec layer, int layerIndex ->
        Matrix sourceData = resolveLayerData(chart.data, layer)
        boolean layerHasOwnData = sourceData != null && !sourceData.is(chart.data)
        List<Integer> rowIndexes = layerHasOwnData
            ? defaultRowIndexes(sourceData.rowCount())
            : panel.rowIndexes
        Mapping mapping = effectiveMapping(chart.mapping, layer)
        List<LayerData> data = runPipeline(context, layer, sourceData, mapping, rowIndexes)
        result << new LayerPanelData(layerIndex: layerIndex, layer: layer, panel: panel, data: data)
      }
    }
    result
  }
```

```groovy
package se.alipsa.matrix.gg.bridge

import se.alipsa.matrix.charm.render.LayerData
import se.alipsa.matrix.core.Matrix

/**
 * Converts Charm {@link LayerData} rows into a {@link Matrix} using ggplot2's column names
 * ({@code colour}, not {@code color}). The first column is {@code PANEL} (1-based panel number,
 * as in ggplot2). Aesthetic columns that are null for every row are omitted; {@code meta}
 * entries (for example {@code density}, {@code binStart}, {@code count}) become additional columns.
 */
class LayerDataMatrix {

  private static final List<String> AESTHETICS = [
      'x', 'y', 'xmin', 'xmax', 'ymin', 'ymax', 'xend', 'yend',
      'colour', 'fill', 'size', 'shape', 'alpha', 'linetype', 'group', 'label', 'tooltip', 'weight'
  ].asImmutable()

  private LayerDataMatrix() {
    // Utility class
  }

  /**
   * Builds a matrix from one layer's per-panel data.
   *
   * @param panels post-pipeline data per panel, in panel order (may be empty)
   * @param name matrix name, e.g. {@code layer_1}
   * @return matrix with one row per datum; zero rows and zero columns when there is no data
   */
  static Matrix toMatrix(List<List<LayerData>> panels, String name) {
    List<LayerData> rows = []
    List<Object> panelIds = []
    (panels ?: []).eachWithIndex { List<LayerData> panelData, int idx ->
      (panelData ?: []).each { LayerData d ->
        rows << d
        panelIds << (idx + 1)
      }
    }
    Map<String, List<Object>> columns = new LinkedHashMap<>()
    if (!rows.isEmpty()) {
      columns['PANEL'] = panelIds
    }
    AESTHETICS.each { String aes ->
      List<Object> values = rows.collect { LayerData d -> aestheticValue(d, aes) }
      if (values.any { it != null }) {
        columns[aes] = values
      }
    }
    Set<String> metaKeys = new LinkedHashSet<>()
    rows.each { LayerData d -> metaKeys.addAll(d.meta.keySet()) }
    metaKeys.each { String key ->
      if (!columns.containsKey(key)) {
        columns[key] = rows.collect { LayerData d -> d.meta[key] }
      }
    }
    if (columns.isEmpty()) {
      return new Matrix(name, [], [], [])
    }
    Matrix.builder().matrixName(name).data(columns).build()
  }

  private static Object aestheticValue(LayerData d, String aes) {
    switch (aes) {
      case 'x' -> d.x
      case 'y' -> d.y
      case 'xmin' -> d.xmin
      case 'xmax' -> d.xmax
      case 'ymin' -> d.ymin
      case 'ymax' -> d.ymax
      case 'xend' -> d.xend
      case 'yend' -> d.yend
      case 'colour' -> d.color
      case 'fill' -> d.fill
      case 'size' -> d.size
      case 'shape' -> d.shape
      case 'alpha' -> d.alpha
      case 'linetype' -> d.linetype
      case 'group' -> d.group
      case 'label' -> d.label
      case 'tooltip' -> d.tooltip
      case 'weight' -> d.weight
      default -> null
    }
  }
}
```

14.8 [ ] Add to `GgCharmCompiler`:

```groovy
  /**
   * Computes the built data of every gg layer through the Charm pipeline, without rendering.
   *
   * @param ggChart source gg chart
   * @return one matrix per gg layer in {@code ggChart.layers} order; annotation layers and layers
   *         that could not be delegated yield an empty matrix
   * @throws IllegalStateException when the chart cannot be adapted to Charm
   */
  List<Matrix> layerData(GgChart ggChart) {
    GgCharmCompilation adaptation = adapt(ggChart)
    if (!adaptation.delegated || adaptation.charmChart == null) {
      String reasons = adaptation?.reasons?.join('; ') ?: 'Unknown adaptation failure'
      throw new IllegalStateException("GG to Charm adaptation failed: ${reasons}")
    }
    RenderConfig config = new RenderConfig(width: ggChart.width, height: ggChart.height)
    List<LayerPanelData> jobs = charmRenderer.computeLayerData(adaptation.charmChart, config)
    // gg layer index -> per-panel data (panel-major order is preserved by appending)
    Map<Integer, List<List<LayerData>>> byGgIndex = [:]
    jobs.each { LayerPanelData job ->
      int ggIdx = adaptation.layerIndexes[job.layerIndex]
      List<List<LayerData>> panels = byGgIndex[ggIdx]
      if (panels == null) {
        panels = []
        byGgIndex[ggIdx] = panels
      }
      panels << job.data
    }
    (0..<ggChart.layers.size()).collect { int ggIdx ->
      LayerDataMatrix.toMatrix(byGgIndex[ggIdx] ?: [], "layer_${ggIdx + 1}")
    }
  }
```

```groovy
  /**
   * Returns the built data of one layer after stat and position adjustment, computed by the
   * same pipeline that renders the chart (ggplot2's {@code layer_data(p, i)}).
   *
   * <p>Columns use ggplot2 names: {@code PANEL} (1-based facet panel), {@code x}, {@code y},
   * {@code xmin}, {@code ymin}, {@code colour}, {@code fill}, {@code group}, ... plus the stat's
   * computed variables (for example {@code density}, {@code binStart}, {@code count}). Stats and
   * positions are computed per facet panel, exactly as rendered. Aesthetics that are null for
   * every row are omitted. Annotation layers return an empty matrix.</p>
   *
   * <pre>
   * Matrix bins = layer_data(ggplot(df, aes(x: 'hwy')) + geom_histogram(bins: 10))
   * </pre>
   *
   * @param chart the chart
   * @param i 1-based layer index in the order layers were added (default 1)
   * @return matrix with one row per built datum
   * @throws IllegalArgumentException if {@code i} is out of range
   */
  static Matrix layer_data(GgChart chart, int i = 1) {
    if (chart == null) {
      throw new IllegalArgumentException('chart cannot be null')
    }
    if (i < 1 || i > chart.layers.size()) {
      throw new IllegalArgumentException("layer index ${i} is out of range 1..${chart.layers.size()}")
    }
    ggplot_build(chart)[i - 1]
  }

  /**
   * Returns the built data of every layer (ggplot2's {@code ggplot_build(p)$data}).
   *
   * @param chart the chart
   * @return one matrix per layer, in the order layers were added
   */
  static List<Matrix> ggplot_build(GgChart chart) {
    if (chart == null) {
      throw new IllegalArgumentException('chart cannot be null')
    }
    new GgCharmCompiler().layerData(chart)
  }
```
