**Goal:** Fix the findings from the 2026-09-20 review of `matrix-charts` (6 reproduced rendering
bugs, 6 should-fix defects, 2 low findings from the last-commit code review, and a set of hygiene
items) and release them as 0.6.0 rather than 0.5.1, because fixes 1–4 change the rendered output
of every bar/col chart and of every axis whose category labels contain digits.

**Architecture:** All fixes live inside the Charm render pipeline (`se.alipsa.matrix.charm.render.*`)
and the `chartexport` helpers. Scale training gains an explicit "training values" collection step
so that geoms can contribute `ymin`/`ymax`/`xmin`/`xmax`/`xend`/`yend` and a zero baseline; the
discrete-vs-continuous decision gets a strict numeric check that lives in `ScaleUtils`; transform
scales generate ticks in data space and are positioned through `transform()` only. Dodge on a
discrete axis is solved by recording a group index/count in `LayerData.meta` during position
adjustment and applying the pixel offset in `BarRenderer`.

**Tech Stack:** Groovy 5.1.1 (`@CompileStatic` enforced globally through
`config/groovy/compileStatic.groovy`), Java 21, gsvg 1.2.0 (`se.alipsa.groovy.svg.*`),
jsvg, PDFBox 3.0.8, JUnit Jupiter 6, `groovier-junit`.

**Spec:** The review findings are reproduced in section "Findings being fixed" below so this
plan is self-contained. Design decisions from `matrix-charts/req/0.5.0-r4-plan.md` (single
Charm engine, per-layer scale overrides, `pipelineCache` memoisation) must be preserved.

2.3 [x] Add to `ScaleUtils`:

```groovy
  /**
   * Decide whether a raw data value is numeric for scale-type inference.
   *
   * <p>Unlike {@link ValueConverter#asBigDecimal(Object)}, which strips non-numeric characters
   * and therefore turns labels such as {@code 'Q1'} into {@code 1}, this check only accepts
   * {@link Number} instances (excluding NaN/Infinity) and strings whose entire trimmed text is a
   * valid decimal literal.</p>
   *
   * @param value raw data value
   * @return true if the value should be treated as numeric
   */
  static boolean isStrictNumeric(Object value) {
    coerceStrictNumber(value) != null
  }

  /**
   * Coerce a raw data value to BigDecimal using strict parsing (see {@link #isStrictNumeric}).
   *
   * @param value raw data value
   * @return the numeric value, or null if the value is not strictly numeric
   */
  static BigDecimal coerceStrictNumber(Object value) {
    if (value == null) {
      return null
    }
    if (value instanceof Number) {
      return ValueConverter.asBigDecimal(value as Number)
    }
    if (value instanceof CharSequence) {
      String text = value.toString().trim()
      if (text.isEmpty()) {
        return null
      }
      try {
        return new BigDecimal(text)
      } catch (NumberFormatException ignored) {
        return null
      }
    }
    null
  }
```

      Object v = meta[key]

        (v as Collection).each { Object item -> if (item != null) values << item }
      } else if (v != null) {
        values << v

   *
   * @param layer the layer (used for geom-specific rules)
